## はじめに {/* #get-started */}

Ghostty をインストールして実行しましょう！
[設定不要](/docs/config#zero-configuration-philosophy)ですぐに使い始められます。

### インストール手順 {/* #installation-instructions */}

macOS 向けにはすぐに実行できるバイナリがあります。Linux ではパッケージを使用するか、ソースからビルドします。
