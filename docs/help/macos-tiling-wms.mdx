---
title: macOS のタイル型ウィンドウマネージャー
description: |-
  Yabai や Aerospace などの macOS のタイル型ウィンドウマネージャーでは、
  Ghostty のタブが別々のウィンドウとして表示されることがあります。
---

Yabai や Aerospace などの macOS のタイル型ウィンドウマネージャーでは、
Ghostty のタブが別々のウィンドウとして表示されることがあります。
これは既知の問題であり、Yabai と Aerospace の両方の課題トラッカーで詳しく報告されています。

Ghostty は macOS のネイティブタブを使用しています。
macOS のネイティブタブは、macOS のウィンドウマネージャー API では別々のウィンドウとして表現されます。
Yabai、Aerospace、その他のタイル型ウィンドウマネージャーは、
この API を使って macOS 上のウィンドウを管理しています。

したがって、これは macOS の API の制限であり、
Ghostty 側でこの問題を解決するためにできることはありません。

<Note>
長期的には、macOS のネイティブタブに依存しない独自のタブ機能を実装したいと考えています。
これにより、macOS のタイル型ウィンドウマネージャーと、よりよく連携できるようになります。
</Note>

## 回避策 {/* #workarounds */}

Ghostty コミュニティでは、使用しているタイル型ウィンドウマネージャーに応じて、
回避策となり得る方法を見つけています。

### Aerospace {/* #aerospace */}

```toml
on-window-detected = [
    {
        if = 'test %{app-bundle-id} = com.mitchellh.ghostty',
        run = 'layout tiling'
    }
]
```

Ghostty のタブが依然として別々のウィンドウとして表示される場合は、`"layout tiling"` を `"layout floating"` に置き換えてみてください。ただし、これにより初回起動時の Ghostty ウィンドウがフローティング状態になります。手動でフローティングを解除できます（デフォルトでは `alt+shift+;` に続けて `f`）。

### Yabai {/* #yabai */}

```
yabai -m signal --add app='^Ghostty$' event=window_created action='yabai -m space --layout bsp'
yabai -m signal --add app='^Ghostty$' event=window_destroyed action='yabai -m space --layout bsp'
```
