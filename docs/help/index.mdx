Ghostty は商業的な後ろ盾のない、個人のサイドプロジェクトです。
そのため、サポートチームや、支援を提供するための専用のリソースはありません。
コミュニティはとても親切で、助けてもらえることがあります。
また、よくある問題と解決方法をできる限り多く文書化するよう努めています。

## よくある問題と解決方法 {/* #common-issues-and-solutions */}

| 問題 | 解決方法 |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| コマンドの実行時や SSH の使用時に「missing or unsuitable terminal」エラーが発生する。 | [Terminfo](/docs/help/terminfo) |
| Yabai や Aerospace などの macOS ウィンドウマネージャーの動作がおかしい。 | [macOS のタイル型ウィンドウマネージャー](/docs/help/macos-tiling-wms) |
| Linux で Ghostty の起動が遅い、またはメモリ使用量が多い。 | [GTK シングルインスタンス](/docs/help/gtk-single-instance)、[`+new-window`](https://ghostty.org/docs/linux/systemd) |
| Linux で「Unable to acquire OpenGL context」エラーが発生する。 | [GTK の OpenGL コンテキスト](/docs/help/gtk-opengl-context) |
| macOS ではデフォルトでログインシェルが使われる。 | [macOS のログインシェル](/docs/help/macos-login-shells) |
| Claude Code や Docker などの CLI ツールが繰り返し点滅したりちらついたりする。 | [同期出力](/docs/help/synchronized-output) |

## バグの報告や機能のリクエスト {/* #reporting-bugs-or-requesting-features */}

どうか、必ず、[GitHub の貢献ガイド](https://github.com/ghostty-org/ghostty/blob/main/CONTRIBUTING.md)を読んでください。

<Important>
  **おそらく GitHub Issues は適切な投稿先ではありません。** このプロジェクトでは、バグや機能のリクエストはすべて、
  より具体的な詳細が明らかになるまで、GitHub Discussions のディスカッションとして扱います。
  その後、必要に応じて GitHub Issues に変換します。詳細は貢献ガイドを参照してください。
</Important>
