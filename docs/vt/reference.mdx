このページでは、Ghostty がサポートする多数の VT シーケンスを一覧にしています。

このページは執筆途中です。Ghostty は、ここに挙げたものよりはるかに多くのシーケンスをサポートしています。また、ここに挙げたシーケンスについても、リンク先のドキュメントの品質にはばらつきがあります。ドキュメントの改善に貢献したい方にとって、とても取り組みやすい領域です。

現在はシーケンスの種類（control、esc、CSI など）で分類し、その中で構文のアルファベット順に並べています。将来的には、分類や検索機能を改善する予定です。

| 名前 | 構文 | 説明 |
|------|------|-------------|
| [BEL](/docs/vt/control/bel) | `0x07`  | ユーザーに警告します（ビープ音）。 |
| [BS](/docs/vt/control/bs) | `0x08`  | カーソルを 1 つ前の位置に移動します。 |
| [TAB](/docs/vt/control/tab) | `0x09`  | カーソルを右側の次のタブストップに移動します。 |
| [LF](/docs/vt/control/lf) | `0x0A`  | カーソルを 1 行下に移動し、必要に応じてスクロールします。 |
| [CR](/docs/vt/control/cr) | `0x0D`  | カーソルを左マージンに移動します。 |
| [DECSC](/docs/vt/esc/decsc) | `ESC 7` | カーソルを保存します。 |
| [DECRC](/docs/vt/esc/decrc) | `ESC 8` | カーソルを復元します。 |
| [IND](/docs/vt/esc/ind) | `ESC D` | カーソルを下に移動し、必要に応じてスクロールします。 |
| [RI](/docs/vt/esc/ri) | `ESC M` | カーソルを上に移動し、必要に応じてスクロールします。 |
| [RIS](/docs/vt/esc/ris) | `ESC c` | 完全リセットを行います。 |
| [DECSCUSR](/docs/vt/csi/decscusr) | `CSI Pn " " q` | カーソルのスタイルを設定します。 |
| [DECKPAM](/docs/vt/esc/deckpam) | `ESC =` | テンキーをアプリケーションモードに設定します。 |
| [DECKPNM](/docs/vt/esc/deckpnm) | `ESC >` | テンキーを数値モードに設定します。 |
| [DECALN](/docs/vt/esc/decaln) | `ESC # 8` | 画面の位置合わせをテストします。 |
| [CUU](/docs/vt/csi/cuu) | `CSI Pn A` | カーソルを上に移動します。 |
| [CUD](/docs/vt/csi/cud) | `CSI Pn B` | カーソルを下に移動します。 |
| [CUF](/docs/vt/csi/cuf) | `CSI Pn C` | カーソルを右に移動します。 |
| [CUB](/docs/vt/csi/cub) | `CSI Pn D` | カーソルを左に移動します。 |
| [CNL](/docs/vt/csi/cnl) | `CSI Pn E` | カーソルを `n` 行下の左端の列に移動します。 |
| [CPL](/docs/vt/csi/cpl) | `CSI Pn F` | カーソルを `n` 行上の左端の列に移動します。 |
| [CUP](/docs/vt/csi/cup) | `CSI Py ; Px H` | カーソルを指定した行と列に移動します。 |
| [CHT](/docs/vt/csi/cht) | `CSI Pn I` | カーソルを右に `n` タブ分移動します。 |
| [ED](/docs/vt/csi/ed) | `CSI Pn J` | 画面を消去します。 |
| [EL](/docs/vt/csi/el) | `CSI Pn K` | 行を消去します。 |
| [DL](/docs/vt/csi/dl) | `CSI Pn M` | カーソル位置で `n` 行を削除します。 |
| [IL](/docs/vt/csi/il) | `CSI Pn L` | カーソル位置に `n` 行を挿入します。 |
| [DCH](/docs/vt/csi/dch) | `CSI Pn P` | カーソル位置で `n` 文字を削除します。 |
| [SU](/docs/vt/csi/su) | `CSI Pn S` | 上に `n` 行スクロールします。 |
| [SD](/docs/vt/csi/sd) | `CSI Pn T` | 下に `n` 行スクロールします。 |
| [ECH](/docs/vt/csi/ech) | `CSI Pn X` | カーソル位置で `n` 文字を消去します。 |
| [CBT](/docs/vt/csi/cbt) | `CSI Pn Z` | カーソルを左に `n` タブ分移動します。 |
| [HPR](/docs/vt/csi/hpr) | `CSI Pn a` | カーソルを現在のカーソル位置を基準とした列に移動します。 |
| [REP](/docs/vt/csi/rep) | `CSI Pn b` | 直前の文字を `n` 回繰り返します。 |
| [VPA](/docs/vt/csi/vpa) | `CSI Py d` | カーソルを指定した行に移動します。 |
| [VPR](/docs/vt/csi/vpr) | `CSI Pn e` | カーソルを現在のカーソル位置を基準として `n` 行下に移動します。 |
| [TBC](/docs/vt/csi/tbc) | `CSI Pn g` | 1 つまたはすべてのタブストップを消去します。 |
| [DSR](/docs/vt/csi/dsr) | `CSI Pn n` | デバイスの状態を報告します。 |
| [DECSTBM](/docs/vt/csi/decstbm) | `CSI Pt ; Pb r` | 上下のマージンを設定します。 |
| [DECSLRM](/docs/vt/csi/decslrm) | `CSI Pl ; Pr s` | 左右のマージンを設定します。 |
| [ICH](/docs/vt/csi/ich) | `CSI Pn @` | カーソル位置に `n` 文字を挿入します。 |
| [HPA](/docs/vt/csi/hpa) | `CSI Px ` ` | カーソルを指定した列に移動します。 |
| [XTSHIFTESCAPE](/docs/vt/csi/xtshiftescape) | `CSI > Pn s` | マウス報告での `shift` 修飾キーの動作を設定します。 |
| [OSC 0] | `OSC 0 ; Pt ST` | ウィンドウアイコンとウィンドウタイトルを変更します。 |
| [OSC 1] | `OSC 1 ; Pt ST` | ウィンドウアイコンを変更します。 |
| [OSC 2] | `OSC 2 ; Pt ST` | ウィンドウタイトルを変更します。 |
| [OSC 4] | `OSC 4 ; Pn ; Pc ST` | パレット色の問い合わせや変更を行います。 |
| [OSC 5] | `OSC 5 ; Pn ; Pc ST` | 特殊色の問い合わせや変更を行います。 |
| [OSC 7] | `OSC 7 ; Pu ; ST` | 作業ディレクトリを変更します。 |
| [OSC 8] | `OSC 8 ; Pp ; Pu ; ST` | ハイパーリンクを開始または終了します。 |
| [OSC 9] | `OSC 9 ; Pt ; ST` | デスクトップ通知を表示します。 |
| [OSC 9;4] | `OSC 9 ; 4 ; Ps ; Pn ; ST` | 進捗状態を報告します。 |
| [OSC 10][OSC 1x] | `OSC 10 ; Pc ST` | 前景色の問い合わせや変更を行います。 |
| [OSC 11][OSC 1x] | `OSC 11 ; Pc ST` | 背景色の問い合わせや変更を行います。 |
| [OSC 12][OSC 1x] | `OSC 12 ; Pc ST` | カーソル色の問い合わせや変更を行います。 |
| [OSC 13][OSC 1x] | `OSC 13 ; Pc ST` | ポインターの前景色の問い合わせや変更を行います。 |
| [OSC 14][OSC 1x] | `OSC 14 ; Pc ST` | ポインターの背景色の問い合わせや変更を行います。 |
| [OSC 15][OSC 1x] | `OSC 15 ; Pc ST` | Tektronix の前景色の問い合わせや変更を行います。 |
| [OSC 16][OSC 1x] | `OSC 16 ; Pc ST` | Tektronix の背景色の問い合わせや変更を行います。 |

| [OSC 21] | `OSC 21 ; Pk = Pv ; ... ST ` | Kitty Color Protocol を使って任意の色の問い合わせや変更を行います。 |
| [OSC 22] | `OSC 22 ; Pt ST ` | ポインターの形状を変更します。 |
