---
title: カーソル水平タブ移動 (CHT)
description: カーソルを右に `n` タブ分移動します。
---

<VTSequence sequence={["CSI", "Pn", "I"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

この操作で有効な右端の列は、ターミナル画面の右端の列と[右マージン](#TODO)のうち、列番号が小さい方です。このシーケンスの動作は、[原点モード](#TODO)が設定されていても変わりません。

カーソルがタブストップ上に来るまで右に移動します。有効な右端の列を越えて移動する場合、カーソルは有効な右端の列にとどまり、操作を終了します。この処理を `n` 回繰り返します。

タブストップは動的であり、[水平タブ設定 (HTS)](#TODO)、[タブ消去 (TBC)](/docs/vt/csi/tbc) などのエスケープシーケンスで設定できます。ターミナルエミュレーターは任意の間隔をデフォルトのタブストップにできますが、8 スペース間隔が最も一般的です。

## 検証 {/* #validation */}

### CHT V-1: 最後の列を越えて右へ移動 {/* #cht-v-1:-right-beyond-last-column */}

```bash
printf "\033[?5W" # reset tab stops
printf "\033[100I" # assuming the test terminal has less than 800 columns
printf "A"
```

```
|_________A|
```

### CHT V-2: タブストップの手前から右へ移動 {/* #cht-v-2:-right-from-before-a-tabstop */}

```bash
printf "\033[?5W" # reset tab stops
printf "\033[1;2H"
printf "A"
printf "\033[I"
printf "X"
```

```
|_A______X_|
```

### CHT V-3: 右マージン {/* #cht-v-3:-right-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tab stops
printf "\033[?69h" # enable left/right margins
printf "\033[3;6s" # scroll region left/right
printf "\033[1;1H" # move cursor in region
printf "X"
printf "\033[I"
printf "A"
```

```
|__AX______|
```
