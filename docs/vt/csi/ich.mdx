---
title: 文字挿入 (ICH)
description: 現在のカーソル位置に空白文字を挿入します。
---

<VTSequence sequence={["CSI", "Pn", "@"]} />

現在のカーソル位置に `n` 個の空白文字を挿入し、既存のセル内容を右にずらします。

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

このシーケンスは常に保留中の折り返し状態を解除します。

カーソル位置が[左右のマージン](#TODO)の外にある場合、このシーケンスは画面を変更しませんが、保留中の折り返し状態はリセットします。

右マージンを越えてずらされた既存のセルは削除されます。挿入されるセルは、現在の SGR 状態に応じた背景色の空白になります。

複数セルにまたがる文字（「橋」など）をずらした結果、セルが半分に分かれる場合、その文字は切り取っても消去してもかまいません。一般的には、画面の右端では切り取り、右マージンでは消去しますが、どちらの動作でも許容されます。

## 検証 {/* #validation */}

### ICH V-1: スクロール領域がなく画面内に収まる場合 {/* #ich-v-1:-no-scroll-region-fits-on-screen */}

```bash
printf "ABC"
printf "\033[1G"
printf "\033[2@"
printf "X"
```

```
|XcABC_____|
```

### ICH V-2: SGR 状態 {/* #ich-v-2:-sgr-state */}

```bash
printf "ABC"
printf "\033[1G"
printf "\033[41m"
printf "\033[2@"
printf "X"
```

```
|c_ABC_____|
```

`c_` の両方のセルは、背景が赤になるはずです。`ABC` のセルのスタイルは変わらないはずです。

### ICH V-3: 内容を画面外にずらす {/* #ich-v-3:-shifting-content-off-the-screen */}

```bash
cols=$(tput cols)
printf "\033[${cols}G"
printf "\033[2D"
printf "ABC"
printf "\033[2D"
printf "\033[2@"
printf "X"
```

```
|_______XcA|
```

### ICH V-4: 左右スクロール領域の内側 {/* #ich-v-4:-inside-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[3G"
printf "ABC"
printf "\033[3G"
printf "\033[2@"
printf "X"
```

```
|__XcA_____|
```

### ICH V-5: 左右スクロール領域の外側 {/* #ich-v-5:-outside-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[3G"
printf "ABC"
printf "\033[1G"
printf "\033[2@"
printf "X"
```

```
|XcABC_____|
```

### ICH V-6: 幅の広い文字の分割 {/* #ich-v-6:-split-wide-character */}

```bash
cols=$(tput cols)
printf "\033[${cols}G"
printf "\033[1D"
printf "橋"
printf "\033[2D"
printf "\033[@"
printf "X"
```

```
|_______Xc_|
```

この場合、最後のセルは空白にしても、複数セルにまたがる文字を切り取ってもかまいません。xterm は文字を切り取りますが、多くの他のターミナルはセルを消去します。
