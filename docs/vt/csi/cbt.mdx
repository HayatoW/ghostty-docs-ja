---
title: カーソル後退タブ移動 (CBT)
description: カーソルを左に `n` タブ分移動します。
---

<VTSequence sequence={["CSI", "Pn", "Z"]} />

この操作で有効な左端の列は最初の列です。[原点モード](#TODO)が有効な場合、この操作で有効な左端の列は[左マージン](#TODO)になります。

カーソルがタブストップ上に来るまで左に移動します。有効な左端の列を越えて移動する場合、カーソルは有効な左端の列にとどまり、操作を終了します。この処理を `n` 回繰り返します。

タブストップは動的であり、[水平タブ設定 (HTS)](#TODO)、[タブ消去 (TBC)](/docs/vt/csi/tbc) などのエスケープシーケンスで設定できます。ターミナルエミュレーターは任意の間隔をデフォルトのタブストップにできますが、8 スペース間隔が最も一般的です。

## 検証 {/* #validation */}

### CBT V-1: 最初の列を越えて左へ移動 {/* #cbt-v-1:-left-beyond-first-column */}

```bash
printf "\033[?5W" # reset tab stops
printf "\033[10Z"
printf "A"
```

```
|Ac________|
```

### CBT V-2: タブストップの後から左へ移動 {/* #cbt-v-2:-left-starting-after-tab-stop */}

```bash
printf "\033[?5W" # reset tab stops
printf "\033[1;10H"
printf "X"
printf "\033[Z"
printf "A"
```

```
|________AX|
```

### CBT V-3: タブストップ上から左へ移動 {/* #cbt-v-3:-left-starting-on-tabstop */}

```bash
printf "\033[?5W" # reset tab stops
printf "\033[1;9H"
printf "X"
printf "\033[1;9H"
printf "\033[Z"
printf "A"
```

```
|A_______X_|
```

### CBT V-4: 原点モードでの左マージン {/* #cbt-v-4:-left-margin-with-origin-mode */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tab stops
printf "\033[?6h" # enable origin mode
printf "\033[?69h" # enable left/right margins
printf "\033[3;6s" # scroll region left/right
printf "\033[1;2H" # move cursor in region
printf "X"
printf "\033[Z"
printf "A"
```

```
|__AX______|
```
