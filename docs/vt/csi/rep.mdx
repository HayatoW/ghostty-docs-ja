---
title: 直前の文字の繰り返し (REP)
description: 直前に表示した文字を `n` 回繰り返します。
---

<VTSequence sequence={["CSI", "Pn", "b"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

xterm では、単一バイトの文字（10 進数で 256 未満）だけがサポートされています。その他の主要なターミナルのほとんどでは、任意の文字がサポートされています。

繰り返される各文字は、手動で入力した場合とまったく同じように動作します。そのため、ソフト折り返し、マージンなども、文字を入力した場合と同じように動作します。

直前に表示した文字とは、何らかの手段で表示された任意の文字です。ユーザーが手動で入力した文字に限定されません。直前に入力された文字がない場合、このシーケンスは何もしません。

## 検証 {/* #validation */}

### REP V-1: 単純な使用 {/* #rep-v-1:-simple-usage */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A"
printf "\033[b"
```

```
|AAc_______|
```

### REP V-2: ソフト折り返し {/* #rep-v-2:-soft-wrap */}

```bash
cols=$(tput cols)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[${cols}G"
printf "A"
printf "\033[b"
```

```
|_________A|
|Ac________|
```
