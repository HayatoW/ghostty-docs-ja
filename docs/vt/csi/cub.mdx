---
title: カーソル後退 (CUB)
description: カーソルを左に `n` セル移動します。
---

<VTSequence sequence={["CSI", "Pn", "D"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

このシーケンスは常に[保留中の折り返し状態](/docs/vt/concepts/cursor#pending-wrap-state)を解除します。

カーソルが移動できる左端の境界は、現在のカーソル列と[左マージン](#TODO)によって決まります。カーソルの開始位置が左マージンより左にある場合、このシーケンスの実行中に限り、左マージンを左端の列に変更します。カーソルが位置できる左端の列は左マージンです。

以上を踏まえ、ターミナルのモードの状態に応じて、カーソル後退には 3 種類の動作があります。可能な動作を以下に示します。競合する場合は、上にある動作が優先されます。

- **拡張逆折り返し**: [折り返し（モード 7）](#TODO) と[拡張逆折り返し（モード 1045）](#TODO) が**両方とも**有効です。
- **逆折り返し**: [折り返し（モード 7）](#TODO) と[逆折り返し（モード 45）](#TODO) が**両方とも**有効です。
- **折り返しなし**: 上記の折り返し動作の条件を満たさない場合のデフォルトの動作です。

**折り返しなし**の動作では、前述の左端の境界を守りながらカーソルを左に `n` セル移動します。左端の境界に達すると、`n` の残りの値に関係なく、左への移動を停止します。カーソルの行は変わりません。

**拡張逆折り返し**の動作では、前述の左端の境界を守りながらカーソルを左に `n` セル移動します。左端の境界に達したとき、`n > 0` であれば、カーソルの 1 行上の[右マージン](#TODO)にカーソルを移動します。カーソルがすでに[上マージン](#TODO)上にある場合は、[下マージン](#TODO)の右マージンに移動します。このモードでは、カーソルの列と行の両方が変わる可能性があります。拡張ではない逆折り返しとの重要な違いは、前の行が折り返されている必要がないことと、下マージンまで折り返すことの 2 点です。

**逆折り返し**（非拡張）の動作では、前述の左端の境界を守りながらカーソルを左に `n` セル移動します。左端の境界に達したとき、`n > 0` で、かつ前の行が折り返されていた場合、カーソルの 1 行上の[右マージン](#TODO)にカーソルを移動します。前の行が折り返されていなかった場合、`n` の値が残っていても、カーソルの左移動操作は終了します。カーソルがすでに[上マージン](#TODO)上にある場合は、カーソルを上に移動しません。この折り返しモードでは、カーソルの行を下マージンまで折り返すことはありません。

**拡張逆折り返し**または**逆折り返し**モードでは、保留中の折り返し状態が設定されている場合、`n` を 1 減らします。これらのモードでは、空の改行上で「バックスペース」を押してカーソルが前の行に戻るかのように、最初のカーソル後退の回数が保留中の折り返し状態によって消費されます。

## 検証 {/* #validation */}

### CUB V-1: 保留中の折り返し状態の解除 {/* #cub-v-1:-pending-wrap-is-unset */}

```bash
cols=$(tput cols)
printf "\033[${cols}G" # move to last column
printf "A" # set pending wrap state
printf "\033[D" # move back one
printf "XYZ"
```

```
|________XY|
|Zc________|
```

### CUB V-2: 逆折り返しが無効な場合の左端の境界 {/* #cub-v-2:-leftmost-boundary-with-reverse-wrap-disabled */}

```bash
printf "\033[?45l" # disable reverse wrap
echo "A"
printf "\033[10D" # back
printf "B"
```

```
|A_________|
|Bc________|
```

### CUB V-3: 逆折り返し {/* #cub-v-3:-reverse-wrap */}

```bash
cols=$(tput cols)
printf "\033[?7h" # enable wraparound
printf "\033[?45h" # enable reverse wrap
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[${cols}G" # move to end of line
printf "AB" # write and wrap
printf "\033[D" # move back two
printf "X"
```

```
|_________Xc
|B_________|
```

### CUB V-4: 拡張逆折り返しでの 1 行の移動 {/* #cub-v-4:-extended-reverse-wrap-single-line */}

```bash
printf "\033[?7h" # enable wraparound
printf "\033[?1045h" # enable extended reverse wrap
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
echo "A"
printf "B"
printf "\033[2D" # move back two
printf "X"
```

```
|A________Xc
|B_________|
```

### CUB V-5: 拡張逆折り返しで下端に折り返し {/* #cub-v-5:-extended-reverse-wrap-wraps-to-bottom */}

```bash
cols=$(tput cols)
printf "\033[?7h" # enable wraparound
printf "\033[?1045h" # enable extended reverse wrap
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[1;3r" # set scrolling region
echo "A"
printf "B"
printf "\033[D" # move back one
printf "\033[${cols}D" # move back entire width
printf "\033[D" # move back one
printf "X"
```

```
|A_________|
|B_________|
|_________Xc
```

### CUB V-6: マージン外での逆折り返し {/* #cub-v-6:-reverse-wrap-outside-of-margins */}

```bash
printf "\033[1;1H"
printf "\033[0J"
printf "\033[?45h"
printf "\033[3r"
printf "\b"
printf "X"
```

```
|__________|
|__________|
|Xc________|
```

### CUB V-7: 保留中の折り返し状態での逆折り返し {/* #cub-v-7:-reverse-wrap-with-pending-wrap-state */}

```bash
cols=$(tput cols)
printf "\033[?45h"
printf "\033[${cols}G"
printf "\033[4D"
printf "ABCDE"
printf "\033[D"
printf "X"
```

```
|_____ABCDX|
```
