---
title: 文字消去 (ECH)
description: カーソル位置を含め、そこから右に `n` セルを空白にします。
---

<VTSequence sequence={["CSI", "Pn", "X"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

消去できる右端の列は、画面の右端の列です。[右マージン](#)はこのシーケンスに影響しません。

このシーケンスは常に保留中の折り返し状態を解除します。カーソルのある行がソフト折り返しされている場合、ソフト折り返しの状態もリセットします。

右端の列までの範囲で、`n` セルを、現在の SGR 状態に応じた背景色の空の文字で置き換えて空白にします。それ以外の SGR 属性は保持しません。

複数セルにまたがる文字が分割される場合は、その文字全体を消去します。たとえば、「橋」が表示されていて、ECH `n = 1` が発行された場合、その文字は 2 セルを占めていますが、文字全体を消去する必要があります。消去した両方のセルは、現在の SGR 状態に応じた現在の背景色で塗られます。

[文字選択属性設定 (DECSCA)](#TODO) が有効であるか、現在アクティブな画面で最後に有効にされた保護モードであった場合、保護属性は設定されていなかったかのように無視され、その属性を持つセルは消去されます。DECSCA が現在無効になっていても、_最後に有効にされた_保護モードが DECSCA である限り、保護属性は無視されます。

DECSCA が現在有効ではなく、現在アクティブな画面で最後に有効にされた保護モードでもなかった場合、保護属性が設定されたセルは尊重され、消去されませんが、`n` の数には含まれます。セルの保護属性がもともと DECSCA によって設定されたかどうかは関係ありません。

## 検証 {/* #validation */}

### ECH V-1: 単純な操作 {/* #ech-v-1:-simple-operation */}

```bash
printf "ABC"
printf "\033[1G"
printf "\033[2X"
```

```
|c_C_____|
```

### ECH V-2: 画面の端を越えた消去 {/* #ech-v-2:-erasing-beyond-edge-of-screen */}

```bash
cols=$(tput cols)
printf "\033[${cols}G"
printf "\033[2D"
printf "ABC"
printf "\033[D"
printf "\033[10X"
```

```
|_____Ac_|
```

### ECH V-3: 保留中の折り返し状態のリセット {/* #ech-v-3:-reset-pending-wrap-state */}

```bash
cols=$(tput cols)
printf "\033[${cols}G" # move to last column
printf "A" # set pending wrap state
printf "\033[X"
printf "X"
```

```
|_______Xc
```

### ECH V-4: SGR 状態 {/* #ech-v-4:-sgr-state */}

```bash
printf "ABC"
printf "\033[1G"
printf "\033[41m"
printf "\033[2X"
```

```
|c_C_____|
```

`c_` の両方のセルは、背景が赤になるはずです。それ以外のすべてのセルのスタイルは変わりません。

### ECH V-5: 複数セルにまたがる文字 {/* #ech-v-5:-multi-cell-character */}

```bash
printf "橋BC"
printf "\033[1G"
printf "\033[X"
printf "X"
```

```
|XcBC____|
```

### ECH V-6: 左右スクロール領域の無視 {/* #ech-v-6:-leftright-scroll-region-ignored */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[1;3s" # scroll region left/right
printf "\033[4G"
printf "ABC"
printf "\033[1G"
printf "\033[4X"
```

```
|c___BC____|
```

### ECH V-7: DECSCA による保護属性の無視 {/* #ech-v-7:-protected-attributes-ignored-with-decsca */}

```bash
printf "\033V"
printf "ABC"
printf "\033[1\"q"
printf "\033[0\"q"
printf "\033[1G"
printf "\033[2X"
```

```
|c_C_______|
```

### ECH V-8: DECSCA がない場合の保護属性の尊重 {/* #ech-v-8:-protected-attributes-respected-without-decsca */}

```bash
printf "\033[1\"q"
printf "ABC"
printf "\033V"
printf "\033[1G"
printf "\033[2X"
```

```
|ABC_______|
```

カーソルは `A` の位置にとどまります。
