---
title: 文字削除 (DCH)
description: 現在のカーソル位置で `n` 文字を削除し、既存のセル内容を左にずらします。
---

<VTSequence sequence={["CSI", "Pn", "P"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

現在のカーソル位置が現在のスクロール領域の外にある場合、このシーケンスは何もしません。カーソルが[左マージン](#TODO)より左、または[右マージン](#TODO)より右にある場合、現在のスクロール領域の外にあるとみなされます。

このシーケンスは保留中の折り返し状態を解除します。ただし、カーソル位置が現在のスクロール領域の外にある場合は、保留中の折り返し状態を解除*しません*。この動作は[文字挿入 (ICH)](/docs/vt/csi/ich) とは異なるため、明示的に記載しています。

削除または移動の対象となるのは、スクロール領域内のセルだけです。右マージンより右のセルは変更されません。右マージンから挿入される空白セルは、現在の SGR 状態に応じた背景色の空白になります。

複数セルにまたがる文字（「橋」など）をずらした結果、セルが半分に分かれる場合、その文字は切り取っても消去してもかまいません。一般的には、画面の右端では切り取り、右マージンでは消去しますが、どちらの動作でも許容されます。

## 検証 {/* #validation */}

### DCH V-1: 単純な文字削除 {/* #dch-v-1:-simple-delete-character */}

```bash
printf "ABC123"
printf "\033[3G"
printf "\033[2P"
```

```
|AB23____|
```

### DCH V-2: SGR 状態 {/* #dch-v-2:-sgr-state */}

```bash
printf "ABC123"
printf "\033[3G"
printf "\033[41m"
printf "\033[2P"
```

```
|AB23____|
```

右端の 2 つのセルは、背景色が赤になるはずです。

### DCH V-3: 左右スクロール領域の外側 {/* #dch-v-3:-outside-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC123"
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[2G"
printf "\033[P"
```

```
|ABC123__|
```

### DCH V-4: 左右スクロール領域の内側 {/* #dch-v-4:-inside-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC123"
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[4G"
printf "\033[P"
```

```
|ABC2_3__|
```

### DCH V-5: 幅の広い文字の分割 {/* #dch-v-5:-split-wide-character */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A橋123"
printf "\033[3G"
printf "\033[P"
```

```
|A_123_____|
```
