---
title: カーソル下移動 (CUD)
description: カーソルを下に `n` セル移動します。
---

<VTSequence sequence={["CSI", "Pn", "B"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

このシーケンスは常に保留中の折り返し状態を解除します。

現在のカーソル位置が[下マージン](#TODO)上またはその上にある場合、カーソルが移動できる最も下の位置は下マージンです。現在のカーソル位置が下マージンより下にある場合、カーソルが移動できる最も下の位置は最終行です。

このシーケンスはスクロールを発生させません。

## 検証 {/* #validation */}

### CUD V-1: カーソル下移動 {/* #cud-v-1:-cursor-down */}

```bash
printf "A"
printf "\033[2B" # cursor down
printf "X"
```

```
|A_________|
|__________|
|_Xc_______|
```

### CUD V-2: 下マージンより上からのカーソル下移動 {/* #cud-v-2:-cursor-down-above-bottom-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\n\n\n\n" # screen is 4 high
printf "\033[1;3r" # set scrolling region
printf "A"
printf "\033[5B" # cursor down
printf "X"
```

```
|A_________|
|__________|
|_Xc_______|
|__________|
```

### CUD V-3: 下マージンより下からのカーソル下移動 {/* #cud-v-3:-cursor-down-below-bottom-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\n\n\n\n\n" # screen is 5 high
printf "\033[1;3r" # set scrolling region
printf "A"
printf "\033[4;1H" # move below region
printf "\033[5B" # cursor down
printf "X"
```

```
|A_________|
|__________|
|__________|
|__________|
|_Xc_______|
```
