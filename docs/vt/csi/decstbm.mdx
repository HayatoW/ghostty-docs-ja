---
title: 上下マージン設定 (DECSTBM)
description: 上下のマージン、別名スクロール領域を設定します。
---

<VTSequence sequence={["CSI", "Pt", ";", "Pb", "r"]} />

パラメーター `t` と `b` は整数値です。どちらかの値がゼロの場合、その値はデフォルト値にリセットされます。`t` のデフォルト値は `1`、`b` のデフォルト値は画面の行数です。

`t` と `b` の値は省略できます。どちらかの値を省略した場合、そのデフォルト値を使用します。`t` を省略して `b` を省略しないことはできない点に注意してください。有効なシーケンスは `CSI t ; b r`、`CSI t r`、`CSI r` だけです。

上の値が下の値以上の場合、このシーケンスは何もしません。スクロール領域には少なくとも 2 行が必要です（`b` は `t` より大きい必要があります）。以降の説明では、`t` と `b` が有効な値であると仮定します。

このシーケンスは保留中の折り返し状態を解除し、カーソルを画面の左上に移動します。[原点モード](#TODO)が設定されている場合、カーソルはスクロール領域の左上に移動します。

スクロール領域をリセットするには、両方の値を「0」に設定してこのシーケンスを呼び出します。これにより `t` と `b` の両方にデフォルト値が適用され、画面全体になります。

上下のマージンは、_スクロール領域_と呼ばれるものを構成します。スクロール領域は、[行挿入](/docs/vt/csi/il)、[カーソル下移動](/docs/vt/csi/cud)など、多くのシーケンスの動作に影響します。スクロール領域は、ターミナルの変更を画面の長方形の領域に制限する、効果的かつ効率的な方法です。

## 検証 {/* #validation */}

### DECSTBM V-1: 画面全体 {/* #decstbm-v-1:-full-screen */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[r" # scroll region top/bottom
printf "\033[T"
```

```
|c_______|
|ABC_____|
|DEF_____|
|GHI_____|
```

### DECSTBM V-2: 上のみ {/* #decstbm-v-2:-top-only */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2r" # scroll region top/bottom
printf "\033[T"
```

```
|ABC_____|
|________|
|DEF_____|
|GHI_____|
```

### DECSTBM V-3: 上下 {/* #decstbm-v-3:-top-and-bottom */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[1;2r" # scroll region top/bottom
printf "\033[T"
```

```
|________|
|ABC_____|
|GHI_____|
```

### DECSTBM V-4: 上と下が同じ値 {/* #decstbm-v-4:-top-equal-to-bottom */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2r" # scroll region top/bottom
printf "\033[T"
```

```
|________|
|ABC_____|
|DEF_____|
|GHI_____|
```
