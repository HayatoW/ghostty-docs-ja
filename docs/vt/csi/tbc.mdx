---
title: タブ消去 (TBC)
description: 1 つまたはすべてのタブストップを消去します。
---

<VTSequence sequence={["CSI", "Pn", "g"]} />

パラメーター `n` は `0` または `3` である必要があります。`n` を省略した場合、`n` のデフォルトは `0` です。

パラメーター `n` が `0` の場合、カーソルの列位置はタブストップではないと指定されます。その列がすでにタブストップではなかった場合、何もしません。

パラメーター `n` が `3` の場合、すべてのタブストップを消去します。

## 検証 {/* #validation */}

### TBC V-1: 単一のタブ消去 {/* #tbc-v-1:-tab-clear-single */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tabs
printf "\t"
printf "\033[g"
printf "\033[1G"
printf "\t"
```

### TBC V-3: すべてのタブストップの消去 {/* #tbc-v-3:-clear-all-tabstops */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tabs
printf "\033[3g"
printf "\033[1G"
printf "\t"
```
