---
title: カーソルスタイル設定 (DECSCUSR)
description: カーソルのスタイルを設定します。
---

<VTSequence sequence={["CSI", "Pn", " ", "q"]} />

`n` を省略した場合、`n` のデフォルトは `0` です。`n` は 0 から 6 までの整数である必要があります。`n` とカーソルスタイルの対応は次のとおりです。

| n   | スタイル                 |
| --- | --------------------- |
| 0   | ターミナルのデフォルト      |
| 1   | 点滅するブロック        |
| 2   | 点滅しないブロック          |
| 3   | 点滅する下線    |
| 4   | 点滅しない下線      |
| 5   | 点滅する縦棒 |
| 6   | 点滅しない縦棒   |

`n = 0` の場合、ターミナルのデフォルトはターミナル次第で、ターミナルの実装によって異なります。デフォルトはターミナルの設定によっても影響を受けることがあります。
