---
title: デバイス状態報告 (DSR)
description: ターミナルに情報を要求します。
---

<VTSequence sequence={["CSI", "Pn", "n"]} />

`n` の値に応じて、ターミナルに情報を要求します。

`n` に指定できる有効な値を以下の段落で説明します。それ以外の `n` の値が指定された場合、このシーケンスは何もしません。

`n = 5` の場合、_動作状態_を要求します。ターミナルはプログラムに `ESC [ 0 n` を返し、異常がないことを示します。

`n = 6` の場合、_カーソル位置_を要求します。ターミナルは `ESC [ y ; x R` の形式でプログラムに応答します。`y` は行、`x` は列で、どちらも 1 から数えます。[原点モード（DEC モード 6）](#TODO) が有効な場合、報告するカーソル位置はスクロール領域の左上を基準とします。

## 検証 {/* #validation */}

### DSR V-1: 動作状態 {/* #dsr-v-1:-operating-status */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[5n"
```

```
|^[[0n_____|
```

### DSR V-2: カーソル位置 {/* #dsr-v-2:-cursor-position */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[2;4H" # move to top-left
printf "\033[6n"
```

```
^[[2;4R
```
