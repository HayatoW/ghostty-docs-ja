---
title: カーソル前進 (CUF)
description: カーソルを右に `n` セル移動します。
---

<VTSequence sequence={["CSI", "Pn", "C"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

このシーケンスは常に保留中の折り返し状態を解除します。

カーソルが移動できる右端の境界は、現在のカーソル列と[右マージン](#TODO)によって決まります。カーソルの開始位置が右マージンより右にある場合、このシーケンスの実行中に限り、右マージンを画面の右端の列に変更します。カーソルが位置できる右端の列は右マージンです。

右端の境界を含む位置までの範囲で、カーソルを右に `n` セル移動します。このシーケンスは折り返しやセル内容の変更を行いません。このシーケンスはターミナルのどのモードにも影響されません。

## 検証 {/* #validation */}

### CUF V-1: 保留中の折り返し状態の解除 {/* #cuf-v-1:-pending-wrap-is-unset */}

```bash
cols=$(tput cols)
printf "\033[${cols}G" # move to last column
printf "A" # set pending wrap state
printf "\033[C" # move forward one
printf "XYZ"
```

```
|_________X|
|YZ________|
```

### CUF V-2: 逆折り返しが無効な場合の右端の境界 {/* #cuf-v-2:-rightmost-boundary-with-reverse-wrap-disabled */}

```bash
printf "A"
printf "\033[500C" # forward larger than screen width
printf "B"
```

```
|A________Bc
```

### CUF V-3: 右マージンより左側 {/* #cuf-v-3:-left-of-the-right-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[1G" # move to left
printf "\033[500C" # forward larger than screen width
printf "X"
```

```
|____X_____|
```

### CUF V-4: 右マージンより右側 {/* #cuf-v-4:-right-of-the-right-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[6G" # move to right of margin
printf "\033[500C" # forward larger than screen width
printf "X"
```

```
|_________X|
```
