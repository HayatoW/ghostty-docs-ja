---
title: 画面消去 (ED)
description: コマンド `n` に応じた動作で画面の内容を消去します。
---

<VTSequence sequence={["CSI", "Pn", "J"]} />

`n` が未設定の場合、`n` の値は 0 です。`n` の有効な値は 0、1、2、3 だけです。それ以外の `n` の値が指定された場合、このシーケンスは実行しません。以降の説明では、`n` が有効な値であると仮定します。

3 を除くすべての有効な `n` の値について、このシーケンスは保留中の折り返し状態を解除します。このシーケンスの実行中、カーソル位置はいかなる状況でも変わりません。

[文字選択属性設定 (DECSCA)](#TODO) が有効であるか、現在アクティブな画面で最後に有効にされた保護モードであった場合、保護属性は無視されます。それ以外の場合、保護属性は尊重されます。この保護属性の処理に関する具体的なロジックの詳細は、[文字消去 (ECH)](/docs/vt/csi/ech) を参照してください。

すべての操作で、複数セルにまたがる文字が分割される場合は、その文字全体を消去します。たとえば、「橋」が表示されていて、消去によって 2 セルの文字の最初または 2 番目のセルだけが消去される場合、両方のセルを消去する必要があります。

このシーケンスは、どのスクロール領域（上、下、左、右）も考慮しません。操作の境界は、表示されている画面全体です。

`n` が `0` の場合、**画面の下側の消去**を実行します。カーソルの右と下にあるすべてのセルを消去します。消去されたセルの背景色は、現在の SGR 状態に応じた色になります。

`n` が `1` の場合、**画面の上側の消去**を実行します。カーソルの左と上にあるすべてのセルを消去します。消去されたセルの背景色は、現在の SGR 状態に応じた色になります。

`n` が `2` の場合、**画面全体を消去**します。これは、上側の消去（`n = 1`）と下側の消去（`n = 0`）の両方を実行することに相当します。

`n` が `3` の場合、**スクロールバック領域だけを消去**します。これは画面の表示部分に影響せず、カーソルも移動しません。スクロールバック領域とは、画面を一番下までスクロールしたときに、画面の表示領域より上にあるターミナルの領域です。

## 検証 {/* #validation */}

### ED V-1: 単純な下側の消去 {/* #ed-v-1:-simple-erase-below */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2H"
printf "\033[0J"
```

```
|ABC_____|
|Dc______|
|________|
```

### ED V-2: 下側の消去と SGR 状態 {/* #ed-v-2:-erase-below-sgr-state */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2H"
printf "\033[41m"
printf "\033[0J"
```

```
|ABC_____|
|Dc______|
|________|
```

カーソルの右と下にあるすべてのセルは、赤く塗られるはずです。

### ED V-3: 下側の消去と複数セルにまたがる文字 {/* #ed-v-3:-erase-below-multi-cell-character */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "AB橋C\n"
printf "DE橋F\n"
printf "GH橋I\n"
printf "\033[2;4H"
printf "\033[0J"
```

```
|AB橋C___|
|DE_c____|
|________|
```

### ED V-4: 単純な上側の消去 {/* #ed-v-4:-simple-erase-above */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2H"
printf "\033[1J"
```

```
|________|
|_cF_____|
|GHI_____|
```

### ED V-5: 単純な全体の消去 {/* #ed-v-5:-simple-erase-complete */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2H"

```

```

|________|
```
