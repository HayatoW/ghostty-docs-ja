---
title: 上スクロール (SU)
description: スクロール領域の上部から `n` 行を削除し、既存の行を上にずらします。
---

<VTSequence sequence={["CSI", "Pn", "S"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

このシーケンスは、カーソル位置をスクロール領域の上端に設定して[行削除 (DL)](/docs/vt/csi/dl) を実行します。DL とはいくつかの違いがあり、以下で説明します。

操作後のカーソル位置は、SU を呼び出した時点から変わってはいけません。保留中の折り返し状態はリセット_しません_。

## 検証 {/* #validation */}

### SU V-1: 単純な使用 {/* #su-v-1:-simple-usage */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2H"
printf "\033[S"
```

```
|DEF_____|
|GHI_____|
```

### SU V-2: 上下スクロール領域 {/* #su-v-2:-topbottom-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;3r" # scroll region top/bottom
printf "\033[1;1H"
printf "\033[S"
```

```
|ABC_____|
|GHI_____|
```

### SU V-3: 左右スクロール領域 {/* #su-v-3:-leftright-scroll-regions */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC123\n"
printf "DEF456\n"
printf "GHI789\n"
printf "\033[?69h" # enable left/right margins
printf "\033[2;4s" # scroll region left/right
printf "\033[2;2H"
printf "\033[S"
```

```
|AEF423__|
|DHI756__|
|G___89__|
```

### SU V-4: 保留中の折り返し状態の保持 {/* #su-v-4:-preserves-pending-wrap */}

```bash
cols=$(tput cols)
printf "\033[1;${cols}H" # move to top-right
printf "\033[2J" # clear screen
printf "A"
printf "\033[2;${cols}H"
printf "B"
printf "\033[3;${cols}H"
printf "C"
printf "\033[S"
printf "X"
```

```
|_______B|
|_______C|
|________|
|X_______|
```

### SU V-5: 上下スクロール領域全体のスクロール {/* #su-v-5:-scroll-full-topbottom-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "top"
printf "\033[5;1H"
printf "ABCDEF"
printf "\033[2;5r" # scroll region top/bottom
printf "\033[4S"
```

```
|top_____|
```
