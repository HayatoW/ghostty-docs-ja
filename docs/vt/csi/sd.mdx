---
title: 下スクロール (SD)
description: スクロール領域の上部に `n` 行を挿入し、既存の行を下にずらします。
---

<VTSequence sequence={["CSI", "Pn", "T"]} />

このシーケンスは、カーソル位置をスクロール領域の上端に設定した[行挿入 (IL)](/docs/vt/csi/il) と機能的に同じです。操作後のカーソル位置は、SD を呼び出した時点から変わってはいけません。

このシーケンスは保留中の折り返し状態を解除します。

## 検証 {/* #validation */}

### SD V-1: 上下スクロール領域の外側 {/* #sd-v-1:-outside-of-topbottom-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[3;4r" # scroll region top/bottom
printf "\033[2;2H"
printf "\033[T"
```

```
|ABC_____|
|DEF_____|
|________|
|GHI_____|
```
