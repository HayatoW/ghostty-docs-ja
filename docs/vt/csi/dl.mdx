---
title: 行削除 (DL)
description: 現在のカーソル位置で `n` 行を削除し、既存の行を上にずらします。
---

<VTSequence sequence={["CSI", "Pn", "M"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

現在のカーソル位置が現在のスクロール領域の外にある場合、このシーケンスは何もしません。カーソルが[上マージン](#TODO)より上、[下マージン](#TODO)より下、[左マージン](#TODO)より左、または[右マージン](#TODO)より右にある場合、現在のスクロール領域の外にあるとみなされます。

このシーケンスは保留中の折り返し状態を解除します。

このシーケンスはカーソルの列を左マージンに移動します。

現在のスクロール領域の上から `n` 行を削除し、既存の行を上にずらします。スクロール領域の下部にできる空間は、現在の SGR 状態に応じた背景色の空白になる必要があります。

[左マージン](#TODO)または[右マージン](#TODO)が設定されている場合、マージン上とその内側のセルだけが削除または移動されます。左マージンより左や右マージンより右にある、その他の既存の内容は変更されません。

複数セルにまたがる文字が分割される場合は、その文字全体を消去します。たとえば、「橋」が左マージンの左側に表示されており、DL によって行を下にずらした結果その文字が分割される場合、そのセルは消去する必要があります。

## 検証 {/* #validation */}

### DL V-1: 単純な行削除 {/* #dl-v-1:-simple-delete-line */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[2;2H"
printf "\033[M"
```

```
|ABC_____|
|GHI_____|
```

### DL V-2: カーソルがスクロール領域の外側 {/* #dl-v-2:-cursor-outside-of-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[3;4r" # scroll region top/bottom
printf "\033[2;2H"
printf "\033[M"
```

```
|ABC_____|
|DEF_____|
|GHI_____|
```

### DL V-3: 上下スクロール領域 {/* #dl-v-3:-topbottom-scroll-regions */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "123\n"
printf "\033[1;3r" # scroll region top/bottom
printf "\033[2;2H"
printf "\033[M"
```

```
|ABC_____|
|GHI_____|
|________|
|123_____|
```

### DL V-4: 左右スクロール領域 {/* #dl-v-4:-leftright-scroll-regions */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC123\n"
printf "DEF456\n"
printf "GHI789\n"
printf "\033[?69h" # enable left/right margins
printf "\033[2;4s" # scroll region left/right
printf "\033[2;2H"
printf "\033[M"
```

```
|ABC123__|
|DHI756__|
|G___89__|
```
