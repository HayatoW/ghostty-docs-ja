---
title: 左右マージン設定 (DECSLRM)
description: 左右のマージンを設定します。
---

<VTSequence sequence={["CSI", "Pl", ";", "Pr", "s"]} />

左右のマージン、別名スクロール領域を設定します。スクロール領域全般については、[上下マージン設定](/docs/vt/csi/decstbm)を参照してください。

パラメーター `l` と `r` は整数値です。どちらかの値がゼロの場合、その値はデフォルト値にリセットされます。`l` のデフォルト値は `1`、`r` のデフォルト値は画面の列数です。

`l` と `r` の値は省略できます。どちらかの値を省略した場合、そのデフォルト値を使用します。`l` を省略して `r` を省略しないことはできない点に注意してください。

このシーケンスには、[左右マージンの有効化（モード 69）](#TODO) が設定されている必要があります。モード 69 が設定されていない場合、このシーケンスは何もせず、左右のマージンも設定されません。

このシーケンスは[カーソル保存（`CSI s`）](#TODO)と競合します。モード 69 が無効な場合は、カーソル保存が呼び出されます。モード 69 が有効な場合、`CSI s` のカーソル保存シーケンスは無効になりますが、カーソル保存は常に `ESC 7` としても利用できます。

左の値が右の値以上の場合、このシーケンスは何もしません。スクロール領域には少なくとも 2 列が必要です（`r` は `l` より大きい必要があります）。以降の説明では、`l` と `r` が有効な値であると仮定します。

このシーケンスは保留中の折り返し状態を解除し、カーソルを画面の左上に移動します。[原点モード](#TODO)が設定されている場合、カーソルはスクロール領域の左上に移動します。

左右のマージンをリセットするには、両方の値を「0」に設定してこのシーケンスを呼び出します。これにより `l` と `r` の両方にデフォルト値が適用され、画面全体になります。モード 69 を解除することでも、左右のマージンはリセットされます。

## 検証 {/* #validation */}

### DECSLRM V-1: 画面全体 {/* #decslrm-v-1:-full-screen */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[?69h" # enable left/right margins
printf "\033[s" # scroll region left/right
printf "\033[X"
```

```
|cBC_____|
|DEF_____|
|GHI_____|
```

### DECSLRM V-2: 左のみ {/* #decslrm-v-2:-left-only */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[?69h" # enable left/right margins
printf "\033[2s" # scroll region left/right
printf "\033[2G" # move cursor to column 2
printf "\033[L"
```

```
|Ac______|
|DBC_____|
|GEF_____|
| HI_____|
```

### DECSLRM V-3: 左右 {/* #decslrm-v-3:-left-and-right */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[?69h" # enable left/right margins
printf "\033[1;2s" # scroll region left/right
printf "\033[2G" # move cursor to column 2
printf "\033[L"
```

```
|_cC_____|
|ABF_____|
|DEI_____|
|GH______|
```

### DECSLRM V-4: 左と右が同じ値 {/* #decslrm-v-4:-left-equal-to-right */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[?69h" # enable left/right margins
printf "\033[2;2s" # scroll region left/right
printf "\033[X"
```

```
|cBC_____|
|DEF_____|
|GHI_____|
```
