---
title: カーソル上移動 (CUU)
description: カーソルを上に `n` セル移動します。
---

<VTSequence sequence={["CSI", "Pn", "A"]} />

パラメーター `n` は 1 以上の整数である必要があります。`n` が 0 以下の場合は、`n` を 1 に調整します。`n` を省略した場合、`n` のデフォルトは 1 です。

このシーケンスは常に保留中の折り返し状態を解除します。

現在のカーソル位置が[上マージン](#TODO)上またはその下にある場合、カーソルが移動できる最も上の位置は上マージンです。現在のカーソル位置が上マージンより上にある場合、カーソルが移動できる最も上の位置は最初の行です。

## 検証 {/* #validation */}

### CUU V-1: カーソル上移動 {/* #cuu-v-1:-cursor-up */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[3;1H"
printf "A"
printf "\033[2A" # cursor up
printf "X"
```

```
|_Xc_______|
|__________|
|A_________|
```

### CUU V-2: 上マージンより下からのカーソル上移動 {/* #cuu-v-2:-cursor-up-below-top-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\n\n\n\n" # screen is 4 high
printf "\033[2;4r" # set scrolling region
printf "\033[3;1H"
printf "A"
printf "\033[5A" # cursor up
printf "X"
```

```
|__________|
|_Xc_______|
|A_________|
|__________|
```

### CUU V-3: 上マージンより上からのカーソル上移動 {/* #cuu-v-3:-cursor-up-above-top-margin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\n\n\n\n\n" # screen is 5 high
printf "\033[3;5r" # set scrolling region
printf "\033[3;1H"
printf "A"
printf "\033[2;1H" # move above region
printf "\033[5A" # cursor up
printf "X"
```

```
|Xc________|
|__________|
|A_________|
|__________|
|__________|
```
