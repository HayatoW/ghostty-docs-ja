---
title: カーソル位置 (CUP)
description: カーソルを `y` 行 `x` 列に移動します。
---

<VTSequence sequence={["CSI", "Py", ";", "Px", "H"]} />

パラメーター `y` と `x` は 1 以上の整数である必要があります。どちらかが 0 以下の場合は、そのパラメーターを 1 に調整します。

`y` と `x` の値は、どちらも 1 から数えます。たとえば、一番上の行は 1 行目、画面の左端の列は 1 列目です。

このシーケンスは常に保留中の折り返し状態を解除します。

[原点モード](#TODO)が設定されて**いない**場合、カーソルは `y` と `x` で指定された行と列に正確に移動します。`y` の最大値は画面の最下行、`x` の最大値は画面の右端の列です。

[原点モード](#TODO)が設定されている場合、カーソル位置はスクロール領域の左上隅を基準に設定されます。`y = 1` は[上マージン](#TODO)に、`x = 1` は[左マージン](#TODO)に対応します。`y` の最大値は[下マージン](#TODO)、`x` の最大値は[右マージン](#TODO)です。

原点モードが設定されている場合、このシーケンスを使用してスクロール領域の境界外にカーソル位置を設定することはできません。

## 検証 {/* #validation */}

### CUP V-1: 通常の使用 {/* #cup-v-1:-normal-usage */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[2;3H"
printf "A"
```

```
|__________|
|__Ac______|
```

### CUP V-2: 画面外 {/* #cup-v-2:-off-the-screen */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[500;500H"
printf "A"
```

```
|__________|
|__________|
|_________Ac
```

### CUP V-3: 原点を基準とした位置 {/* #cup-v-3:-relative-to-origin */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[2;3r" # scroll region top/bottom
printf "\033[?6h" # origin mode
printf "\033[1;1H" # move to top-left
printf "X"
```

```
|__________|
|X_________|
```

### CUP V-4: 左右マージンがある場合の原点を基準とした位置 {/* #cup-v-4:-relative-to-origin-with-leftright-margins */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[2;3r" # scroll region top/bottom
printf "\033[?6h" # origin mode
printf "\033[1;1H" # move to top-left
printf "X"
```

```
|__________|
|__X_______|
```

### CUP V-5: スクロール領域と原点モードでの制限 {/* #cup-v-5:-limits-with-scroll-region-and-origin-mode */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[3;5s" # scroll region left/right
printf "\033[2;3r" # scroll region top/bottom
printf "\033[?6h" # origin mode
printf "\033[500;500H" # move to top-left
printf "X"
```

```
|__________|
|__________|
|____X_____|
```

### CUP V-6: 保留中の折り返し状態の解除 {/* #cup-v-6:-pending-wrap-is-unset */}

```bash
cols=$(tput cols)
printf "\033[${cols}G" # move to last column
printf "A" # set pending wrap state
printf "\033[1;1H"
printf "X"
```

```
|Xc_______X|
```
