---
title: 行消去 (EL)
description: コマンド `n` に応じた動作で行の内容を消去します。
---

<VTSequence sequence={["CSI", "Pn", "K"]} />

`n` が未設定の場合、`n` の値は 0 です。`n` の有効な値は 0、1、2 だけです。それ以外の `n` の値が指定された場合、このシーケンスは実行しません。以降の説明では、`n` が有効な値であると仮定します。

すべての有効な `n` の値について、このシーケンスは保留中の折り返し状態を解除します。このシーケンスの実行中、カーソル位置はいかなる状況でも変わりません。

[文字選択属性設定 (DECSCA)](#TODO) が有効であるか、現在アクティブな画面で最後に有効にされた保護モードであった場合、保護属性は無視されます。それ以外の場合、保護属性は尊重されます。この保護属性の処理に関する具体的なロジックの詳細は、[文字消去 (ECH)](/docs/vt/csi/ech) を参照してください。

すべての操作で、複数セルにまたがる文字が分割される場合は、その文字全体を消去します。たとえば、「橋」が表示されていて、消去によって 2 セルの文字の最初または 2 番目のセルだけが消去される場合、両方のセルを消去する必要があります。

`n` が `0` の場合、**行の右側の消去**を実行します。行の右側の消去は、カーソル位置を含めてカーソルから行末までの残りの列数を `n` に設定した[文字消去 (ECH)](/docs/vt/csi/ech) と同等です。行がソフト折り返しされている場合、消去するのはその 1 行だけで、折り返し先までは消去しません。さらに、その行の折り返し状態をリセットし、折り返された行として扱われなくなります。

`n` が `1` の場合、**行の左側の消去**を実行します。カーソル位置を含めてその左側の `n` セルを空白文字で置き換え、現在の SGR 状態に応じた背景色で塗ります。空白にできる左端の列は、画面の最初の列です。[左マージン](#TODO)はこの操作に影響しません。

`n` が `2` の場合、**行全体を消去**します。これは、左側の消去（`n = 1`）と右側の消去（`n = 0`）の両方を実行することに相当します。

## 検証 {/* #validation */}

### EL V-1: 単純な右側の消去 {/* #el-v-1:-simple-erase-right */}

```bash
printf "ABCDE"
printf "\033[3G"
printf "\033[0K"
```

```
|ABc_____|
```

### EL V-2: 右側の消去による保留中の折り返し状態のリセット {/* #el-v-2:-erase-right-resets-pending-wrap */}

```bash
cols=$(tput cols)
printf "\033[${cols}G" # move to last column
printf "A" # set pending wrap state
printf "\033[0K"
printf "X"
```

```
|_______X|
```

カーソルは「X」の位置にあるはずです。

### EL V-3: 右側の消去と SGR 状態 {/* #el-v-3:-erase-right-sgr-state */}

```bash
printf "ABC"
printf "\033[2G"
printf "\033[41m"
printf "\033[0K"
```

```
|Ac______|
```

`c` から画面の右端までのセルは、すべて背景が赤になるはずです。

### EL V-4: 右側の消去と複数セルにまたがる文字 {/* #el-v-4:-erase-right-multi-cell-character */}

```bash
printf "AB橋DE"
printf "\033[4G"
printf "\033[0K"
```

```
|AB_c____|
```

### EL V-5: 右側の消去での左右スクロール領域の無視 {/* #el-v-5:-erase-right-leftright-scroll-region-ignored */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABCDE"
printf "\033[?69h" # enable left/right margins
printf "\033[1;3s" # scroll region left/right
printf "\033[2G"
printf "\033[0K"
```

```
|Ac________|
```

### EL V-6: 右側の消去での DECSCA による保護属性の無視 {/* #el-v-6:-erase-right-protected-attributes-ignored-with-decsca */}

```bash

printf "\033[1\"q"
printf "\033[0\"q"
printf "\033[2G"
printf "\033[0K"
```


### EL V-7: DECSCA がない場合の保護属性の尊重 {/* #el-v-7:-protected-attributes-respected-without-decsca */}

```bash

printf "\033[0K"
printf "\033[1K"

```

```
|ABCDE_____|
```
