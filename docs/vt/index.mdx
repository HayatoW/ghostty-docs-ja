---
title: ターミナル API (VT)
description: |-
  Ghostty で動作するアプリケーションを作成する開発者向けの API です。
---

ターミナル内で動作するプログラムは、**制御シーケンス**を使ってターミナルとやり取りします。制御シーケンスは、ターミナルがコマンドとして解釈する一連の特殊文字です。**VT シーケンス**や**エスケープコード**と呼ばれることもあります。

サポートされているシーケンスの完全な一覧は、[リファレンス](/docs/vt/reference)を参照してください。制御シーケンスの概念的な概要については、[概念のページ](/docs/vt/concepts/sequences)を参照してください。このページでは、Ghostty の制御シーケンスのサポート状況の概要を説明します。
