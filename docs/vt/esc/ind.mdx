---
title: インデックス (IND)
description: カーソルを 1 セル下に移動し、必要に応じてスクロールします。
---

<VTSequence sequence={["ESC", "D"]} />

このシーケンスは常に保留中の折り返し状態を解除します。

カーソルがちょうど下マージン上にあり、[左マージン](#TODO)と[右マージン](#TODO)の上またはその内側にある場合、1 行[上にスクロール](#TODO)します。スクロール領域がターミナル画面全体で、ターミナルが[プライマリ画面](#TODO)を使用している場合、スクロールバックが作成されることがあります。詳細は[スクロール](#TODO)のドキュメントを参照してください。

カーソルがスクロール領域の外にあるか、スクロール領域の下マージン上にない場合、`n = 1` で[カーソル下移動](/docs/vt/csi/cud)操作を実行します。

このシーケンスがスクロールするのは、カーソルがちょうど下マージン上にあり、スクロール領域のその他の境界の内側にある場合だけです。カーソルがスクロール領域の外にあり、ターミナルの最下行上にある場合、カーソルは移動しません。

## 検証 {/* #validation */}

### IND V-1: スクロール領域がなく画面の上端にある場合 {/* #ind-v-1:-no-scroll-region-top-of-screen */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A"
printf "\033D" # index
printf "X"
```

```
|A_________|
|_Xc_______|
```

### IND V-2: プライマリ画面の下端 {/* #ind-v-2:-bottom-of-primary-screen */}

```bash
lines=$(tput lines)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[${lines};1H" # move to bottom-left
printf "A"
printf "\033D" # index
printf "X"
```

```
|A_________|
|_Xc_______|
```

### IND V-3: スクロール領域の内側 {/* #ind-v-3:-inside-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[1;3r" # scroll region
printf "A"
printf "\033D" # index
printf "X"
```

```
|A_________|
|_Xc_______|
```

### IND V-4: スクロール領域の下端 {/* #ind-v-4:-bottom-of-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[1;3r" # scroll region
printf "\033[4;1H" # below scroll region
printf "B"
printf "\033[3;1H" # move to last row of region
printf "A"
printf "\033D" # index
printf "X"
```

```
|__________|
|A_________|
|_Xc_______|
|B_________|
```

### IND V-5: スクロール領域がある場合のプライマリ画面の下端 {/* #ind-v-5:-bottom-of-primary-screen-with-scroll-region */}

```bash
lines=$(tput lines)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[1;3r" # scroll region
printf "\033[3;1H" # move to last row of region
printf "A"
printf "\033[${lines};1H" # move to bottom-left
printf "\033D" # index
printf "X"
```

```
|__________|
|__________|
|A_________|
|__________|
|Xc________|
```

### IND V-6: 左右スクロール領域の外側 {/* #ind-v-6:-outside-of-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margins
printf "\033[1;3r" # scroll region top/bottom
printf "\033[3;5s" # scroll region left/right
printf "\033[3;3H"
printf "A"
printf "\033[3;1H"
printf "\033D" # index
printf "X"
```

```
|__________|
|__________|
|XcA_______|
```

### IND V-7: 左右スクロール領域の内側 {/* #ind-v-7:-inside-of-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J"   # clear screen
printf "AAAAAA\n"
printf "AAAAAA\n"
printf "AAAAAA"
printf "\033[?69h" # enable left/right margins
printf "\033[1;3s" # set scroll region left/right
printf "\033[1;3r" # set scroll region top/bottom
printf "\033[3;1H" # Move to bottom left
printf "\033D" # index
```

```
|AAAAAA____|
|AAAAAA____|
|c__AAA____|
```
