---
title: 画面位置合わせテスト (DECALN)
description: マージンをリセットし、カーソルを左上に移動し、画面を `E` で埋めます。
---

<VTSequence sequence={["ESC", "#", "8"]} />

上下左右のマージンをリセットし、[原点モード](#TODO)を解除します。カーソルは画面の左上隅に移動します。

太字、点滅など、スタイルに関するすべての SGR 属性を解除します。SGR の前景色と背景色は保持します。[保護属性](#TODO)は解除しません。

画面全体を文字 `E` で埋めます。文字 `E` は現在の SGR 設定を無視し、スタイルなしで書き込まれます。

## 検証 {/* #validation */}

### DECALN V-1: 単純な使用 {/* #decaln-v-1:-simple-usage */}

```bash
printf "\033#8"
```

```
|EEEEEEEE|
|EEEEEEEE|
|EEEEEEEE|
```

### DECALN V-2: マージンのリセット {/* #decaln-v-2:-reset-margins */}

```bash
printf "\033[2;3r" # scroll region top/bottom
printf "\033#8"
printf "\033[T"
```

```
|c_______|
|EEEEEEEE|
|EEEEEEEE|
```
