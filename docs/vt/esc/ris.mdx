---
title: 完全リセット (RIS)
description: ターミナルを初期状態にリセットします。
---

<VTSequence sequence={["ESC", "c"]} />

完全リセット操作では、次の処理を行います。

- カーソルの形状をデフォルトに設定します。
- スクロール領域を画面全体にリセットします。
- [左右マージンモード（モード 69）](#TODO) を無効にします。
- [原点モード（モード 6）](#TODO) を無効にします。
- カーソルの前景色と背景色を解除します。
- 文字セットをデフォルトにリセットします。
- [カーソルキーモード (DECCKM)](#TODO) をリセットします。
- [キーボード入力の無効化 (KAM)](#TODO) をリセットします。
- [アプリケーションキーパッドモード](/docs/vt/esc/deckpnm)をリセットします。
- xterm のキーボード修飾キーの状態をデフォルトにリセットします。
- カーソルの[保護属性](#TODO)を無効にします。
- すべての[保護領域](#TODO)を無効にします。
- すべての[マウス追跡モード](#TODO)をリセットします。
- タブストップをデフォルトにリセットします。
- [送受信モード（モード 12）](#TODO) を有効にします。
- [バックスペースによる delete の送信（モード 67）](#TODO) をリセットします。
- プライマリ画面に戻り、その画面を消去します。
- カーソルを左上隅に移動します。
- 保留中の折り返し状態をリセットします。
- 保存されたカーソルの状態をリセットします。
