---
title: 逆インデックス (RI)
description: カーソルを 1 セル上に移動し、必要に応じてスクロールします。
---

<VTSequence sequence={["ESC", "M"]} />

このシーケンスは保留中の折り返し状態を解除しません。

カーソルがちょうど[上マージン](/docs/vt/csi/decstbm)上にあり、[左右のマージン](/docs/vt/csi/decslrm)の内側にある場合、`n = 1` で[下スクロール (SD)](/docs/vt/csi/sd) を呼び出します。これで操作は終了します。

それ以外の場合、スクロールは不要です。`n = 1` で[カーソル上移動](/docs/vt/csi/cuu)操作を実行します。

## 検証 {/* #validation */}

### RI V-1: スクロール領域がなく画面の上端にある場合 {/* #ri-v-1:-no-scroll-region-top-of-screen */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A\n"
printf "B\n"
printf "C\n"
printf "\033[1;1H" # move to top-left
printf "\033M" # reverse index
printf "X"
```

```
|Xc________|
|A_________|
|B_________|
|C_________|
```

### RI V-2: スクロール領域がなく画面の上端ではない場合 {/* #ri-v-2:-no-scroll-region-not-top-of-screen */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A\n"
printf "B\n"
printf "C\n"
printf "\033[2;1H"
printf "\033M" # reverse index
printf "X"
```

```
|Xc________|
|B_________|
|C_________|
```

### RI V-3: 上下スクロール領域 {/* #ri-v-3:-topbottom-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A\n"
printf "B\n"
printf "C\n"
printf "\033[2;3r" # scroll region
printf "\033[2;1H"
printf "\033M" # reverse index
```

```
|A_________|
|c_________|
|B_________|
```

### RI V-4: 上下スクロール領域の外側 {/* #ri-v-4:-outside-of-topbottom-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "A\n"
printf "B\n"
printf "C\n"
printf "\033[2;3r" # scroll region
printf "\033[1;1H"
printf "\033M" # reverse index
```

```
|A_________|
|B_________|
|C_________|
```

### RI V-5: 左右スクロール領域 {/* #ri-v-5:-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[?69h" # enable left/right margins
printf "\033[2;3s" # scroll region left/right
printf "\033[1;2H"
printf "\033M"
```

```
|A_________|
|DBC_______|
|GEF_______|
|_HI_______|
```

### RI V-6: 左右スクロール領域の外側 {/* #ri-v-6:-outside-leftright-scroll-region */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "ABC\n"
printf "DEF\n"
printf "GHI\n"
printf "\033[?69h" # enable left/right margins
printf "\033[2;3s" # scroll region left/right
printf "\033[2;1H"
printf "\033M"
```

```
|ABC_______|
|DEF_______|
|GHI_______|
```

カーソルは `A` の位置にあります。
