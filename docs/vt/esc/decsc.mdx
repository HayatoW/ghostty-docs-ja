---
title: カーソル保存 (DECSC)
description: カーソル復元 (DECRC) で復元できる、カーソルに関連するさまざまな状態を保存します。
---

<VTSequence sequence={["ESC", "7"]} />

次の属性を保存します。

- 画面の絶対座標でのカーソルの行と列
- 文字セット
- 保留中の折り返し状態
- SGR 属性
- [原点モード（DEC モード 6）](#TODO)

同時に保存できるカーソルは 1 つだけです。カーソル保存を繰り返すと、前に保存したカーソルが上書きされます。

プライマリ画面と代替画面は、保存したカーソルの状態をそれぞれ別に持ちます。プライマリ画面で保存したカーソルには代替画面からアクセスできず、その逆も同様です。

## 検証 {/* #validation */}

### SC V-1: カーソル位置 {/* #sc-v-1:-cursor-position */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[1;5H"
printf "A"
printf "\0337" # Save Cursor
printf "\033[1;1H"
printf "B"
printf "\0338" # Restore Cursor
printf "X"
```

```
|B___AX____|
```

### SC V-2: 保留中の折り返し状態 {/* #sc-v-2:-pending-wrap-state */}

```bash
cols=$(tput cols)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[${cols}G"
printf "A"
printf "\0337" # Save Cursor
printf "\033[1;1H"
printf "B"
printf "\0338" # Restore Cursor
printf "X"
```

```
|B________A|
|X_________|
```

### SC V-3: SGR 属性 {/* #sc-v-3:-sgr-attributes */}

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[1;4;33;44m"
printf "A"
printf "\0337" # Save Cursor
printf "\033[0m"
printf "B"
printf "\0338" # Restore Cursor
printf "X"
```

```
|AX________|
```

「A」と「X」は同じスタイルになるはずです。
