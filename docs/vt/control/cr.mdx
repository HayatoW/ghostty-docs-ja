---
title: 復帰 (CR)
description: カーソルを左端の列に移動します。
---

<VTSequence sequence="CR" />

このシーケンスは常に保留中の折り返し状態を解除します。

[原点モード（モード 6）](#TODO) が有効な場合、カーソルをスクロール領域の[左マージン](#TODO)に設定して操作を終了します。

原点モードが設定されて*おらず*、カーソルが左マージン上またはその右にある場合、カーソルを左マージンに設定します。カーソルが左マージンより左にある場合は、ターミナルの左端の列に移動します。

## 検証 {/* #validation */}

### CR V-1: 保留中の折り返し状態の解除 {/* #cr-v-1:-pending-wrap-is-unset */}

```bash
cols=$(tput cols)
printf "\033[${cols}G" # move to last column
printf "A" # set pending wrap state
printf "\r"
printf "X"
echo
```

```
|X________A|
|c_________|
```

### CR V-2: 左マージン {/* #cr-v-2:-left-margin */}

```bash
cols=$(tput cols)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margin mode
printf "\033[2;5s" # set left/right margin
printf "\033[4G"
printf "A"
printf "\r"
printf "X"
```

```
|_XcA______|
```

### CR V-3: 左マージンより左側 {/* #cr-v-3:-left-of-left-margin */}

```bash
cols=$(tput cols)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?69h" # enable left/right margin mode
printf "\033[2;5s" # set left/right margin
printf "\033[4G"
printf "A"
printf "\033[1G"
printf "\r"
printf "X"
```

```
|Xc_A______|
```

### CR V-3: 原点モードでの左マージン {/* #cr-v-3:-left-margin-with-origin-mode */}

```bash
cols=$(tput cols)
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?6h" # enable origin mode
printf "\033[?69h" # enable left/right margin mode
printf "\033[2;5s" # set left/right margin
printf "\033[4G"
printf "A"
printf "\033[1G"
printf "\r"
printf "X"
```

```
|_XcA______|
```
