---
title: 動的色のリセット (OSC 110–119)
description: インデックスに基づいて動的色をリセットします。
---

<VTSequence sequence={["OSC", "Pn", "ST"]} />

`n` が `110` から `119` までの場合、`n` に対応する[動的色]をリセットします。

[動的色]: /docs/vt/concepts/colors#dynamic-colors

`n` と動的色の対応は次のとおりです。

| `n`  | 色                      |
|------|----------------------------|
| `110` | 前景色           |
| `111` | 背景色           |
| `112` | カーソル色               |
| `113` | ポインターの前景色   |
| `114` | ポインターの背景色   |
| `115` | Tektronix の前景色 |
| `116` | Tektronix の背景色 |
| `117` | 強調表示の背景色 |
| `118` | Tektronix のカーソル色     |
| `119` | 強調表示の前景色 |

> [!NOTE]
>
> 現在、Ghostty がサポートしている `n` は `110` から `112` までだけです。それ以外の動的色はすべて無視されます。

> [!NOTE]
>
> xterm では、`n` の後に末尾のセミコロン（`;`）を付けることができます。
