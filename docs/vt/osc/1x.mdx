---
title: 動的色の問い合わせと変更 (OSC 10–19)
description: インデックスに基づいて動的色の問い合わせや変更を行います。
---

<VTSequence sequence={["OSC", "Pn", ";", "Pc", "ST"]} />

`n` が `10` から `19` までの場合、`c` の値に応じて、`n` に対応する[動的色]の問い合わせまたは変更を行います。`c` はセミコロン（`;`）で区切って**複数回**指定できます。

`c` として単一の文字 `?` を指定すると、ターミナルはインデックス `n` の動的色の[色指定]を返します。`c` が有効な色指定であれば、それに従って動的色を変更します。

[動的色]: /docs/vt/concepts/colors#dynamic-colors
[色指定]: /docs/vt/concepts/colors#color-specifications

シーケンスにさらに `c` が残っている場合、`n` を 1 増やして処理を繰り返します。

`n` と動的色の対応は次のとおりです。

| `n`  | 色                      |
|------|----------------------------|
| `10` | 前景色           |
| `11` | 背景色           |
| `12` | カーソル色               |
| `13` | ポインターの前景色   |
| `14` | ポインターの背景色   |
| `15` | Tektronix の前景色 |
| `16` | Tektronix の背景色 |
| `17` | 強調表示の背景色 |
| `18` | Tektronix のカーソル色     |
| `19` | 強調表示の前景色 |

> [!NOTE]
>
> 現在、Ghostty がサポートしている `n` は `10` から `12` までだけです。それ以外の動的色はすべて無視されます。

たとえば、このシーケンスは背景色とカーソル色をそれぞれ `red` と `blue` に変更します。

<VTSequence sequence={["OSC", "11", ";", "red", ";", "blue", "ST"]} />

これは、OSC 11 と OSC 12 を組み合わせたものと同等です。

<VTSequence sequence={["OSC", "11", ";", "red", "ST"]} />
<VTSequence sequence={["OSC", "12", ";", "blue", "ST"]} />
