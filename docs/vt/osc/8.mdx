ハイパーリンクの開始を示します。このシーケンス以降のセルは、パラメーター `p` も URI もないシーケンスによってハイパーリンクの終了が示されるまで、すべて URI `u` へのハイパーリンクの一部とみなされます。

<VTSequence sequence={["OSC", "8", ";", ";", "ST"]} />

パラメーターは、等号（`=`）で結合したキーと値の組を、コロン（`:`）で区切ったものです。現在認識されるパラメーターは `id` だけです。これは、同じ URI を共有する、同一のハイパーリンクオブジェクトに属する別々のセルを関連付けます。ターミナルは主に、ユーザーのカーソルがセルの上にあるときに、関連付けられたすべてのセルを強調表示するためにこの情報を使用しますが、他の用途にも使用できます。

このシーケンスの一部として `file://` URI を指定する場合、追加の要件としてホスト名を指定する必要があり、指定しない場合、ターミナルはその処理を拒否します。これは、ターミナルのユーザーがリモートマシンへのアクセスに SSH をよく使用し、ホスト名のないファイルリンクが、存在するかどうかわからないローカルファイルへの参照として誤って解釈される可能性があるためです。
