Ghostty は、幅広い状況に対応する検出処理とコードによって、Linux で「そのまま動く」よう大いに努力しています。
しかし、Linux ディストリビューション、デスクトップ環境、ランチャーなどは多様なため、完璧には対応できず、
環境によっては追加の注意事項が必要です。

このセクションでは、Ghostty の Linux 専用機能や、特定の Linux ディストリビューションおよび環境との
連携に関するドキュメントなど、Linux 固有の情報を扱います。

<Note>
  このセクションは Linux ユーザー向けに Linux に特化していますが、Ghostty は macOS でも同じように
  第一級のサポートを提供しており、Swift で書かれ、Xcode でビルドされたネイティブアプリケーションがあります。
</Note>

## サポートする GTK/Adwaita のバージョン {/* #supported-gtkadwaita-versions */}

以下の表は、Ghostty の各バージョンで必要となる GTK と Adwaita の最小バージョンを示しています。

| Ghostty のバージョン | GTK のバージョン | Adwaita のバージョン |
| --------------- | ----------- | --------------- |
| 1.4.x           | 4.18        | 1.7             |
| 1.3.x           | 4.14        | 1.5             |
| 1.2.x           | 4.14        | 1.5             |
| 1.1.x           | 4.8         | 1.2             |

### 方針 {/* #policy */}

Ghostty で必要となる GTK と Adwaita の最小バージョンは、Ghostty のマイナーリリース時点で、
Debian、Fedora、Ubuntu の最新の LTS リリースで利用できる最小バージョンです。
Ghostty のバージョン番号 `X.Y.Z` では、`Y` がマイナーリリースを表します。

パッチリリースで依存関係の要件が引き上げられることはないため、ユーザーは同じマイナーリリース内で、
常に安心して最新のパッチリリースに更新できます。
Ghostty のバージョン番号 `X.Y.Z` では、`Z` がパッチリリースを表します。

Ghostty はさらに多くのディストリビューションをサポートしていますが、
Debian、Fedora、Ubuntu は、パッケージリポジトリの運用が特に保守的で、
ほかの主要なディストリビューションと比べて最も古いバージョンを含む傾向があるため、明示的に挙げています。

<Note>
  **なぜ古い GTK/Adwaita バージョンのサポートを続けないのでしょうか？**
  古い GTK/Adwaita バージョンに機能のサポートをバックポートすることは、保守の観点から現実的ではありません。
  ある程度を超えるとウィジェットツリーが過度に複雑になり、対応バージョンの拡散によってテストがますます難しくなります。
  現在、古い GTK/Adwaita バージョンで GUI の操作をテストするための堅牢な仕組みは、手動テスト以外にはありません。
</Note>

<Note>
  **では、古い GTK/Adwaita バージョンでは Ghostty を使えないのでしょうか？** 必ずしもそうではありません。
  上の表にある、お使いの GTK/Adwaita バージョンに対応した Ghostty のバージョンを引き続き使用できます。
  GTK/Adwaita のバージョンが表の最小要件よりも古い場合は、残念ながら Ghostty を使用できません。申し訳ありません。
</Note>

### その他の依存関係 {/* #other-dependencies */}

ほかの依存関係は通常、API がはるかに安定しているため、GTK や Adwaita よりも幅広いバージョンをサポートする傾向があります。
原則として、すべての依存関係に上記と同じ方針を適用しますが、ほかの依存関係については、より柔軟に対応することがあります。
