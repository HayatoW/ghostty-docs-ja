Ghostty 1.3.1 には、**15 人のコントリビューター**による
**100 件のコミット**が含まれています。主に macOS を中心に、
1.3.0 で発生したリグレッションを修正するパッチリリースで、
いくつかの個別の改善も含まれています。

## ハイライト {/* #highlights */}

### macOS でのマウス選択に関するバグの修正 {/* #macos-mouse-selection-bugs-fixed */}

関連 PR: GH-11276

Ghostty 1.3.0 の macOS 版には、フォーカスの変更後に実際には行っていない
マウス操作が検出され、意図しないドラッグ、選択、スクロールが発生する
目立ったバグがありました。

この問題は解消されました。

## 変更履歴の全文 {/* #full-changelog */}

[GitHub でクローズ済みの Issue の全一覧](https://github.com/ghostty-org/ghostty/milestone/13?closed=1)。

各セクションでは、なるべく改善を先に、バグ修正を後に記載しています。

- 新しい設定: `progress-style` で OSC 9;4 の進捗バーを表示するかどうかを
  制御でき、進捗バーを完全に無効にすることもできます。GH-11289
- 新しいキーバインドのアクション `set_surface_title:<title>` と
  `set_tab_title:<title>` を使うと、キーバインドやアクションを呼び出せる
  ほかの場所からタイトルを直接設定できます。GH-11373 GH-11316
- `working-directory` の設定で `~/` のパスを展開するようになりました。GH-11337
  GH-11336
- `jump_to_prompt:next` で後続のプロンプトに移動する際、複数行のプロンプトを
  正しく扱うようになりました。GH-11331 GH-11330

### シェル統合 {/* #shell-integration */}

- zsh: プロンプトのマーク付けと、動的なテーマやプロンプトの再構築処理との
  互換性を向上させました。GH-11367
- bash: コマンド置換を含む複数行の `PS1` プロンプトが、マークの挿入処理で
  壊れなくなりました。GH-11369
- bash: Readline の vi モード表示を再描画しても余分な改行が入らなくなりました。
  GH-11377 GH-10953

### macOS {/* #macos */}

- macOS: GTK と同様にキーバインドで `paste_from_clipboard` に `performable:`
  を指定できるようになりました。GH-11328 GH-10751
- macOS: フォーカスの変更後に古いマウスの状態が残り、意図しないドラッグや
  選択が起こる問題を修正しました。GH-11276 GH-11319
- macOS: 一部の設定で、タブを開くとウィンドウのサイズが意図せず変わる
  リグレッションを修正しました。GH-11313 GH-11322 GH-11380
- macOS: App Support のパスから設定ファイルを読み込む際、設定の循環参照を
  検出できない問題を修正しました。GH-11323 GH-11326
- macOS: タブのタイトルをその場で編集した際、編集を確定またはキャンセルすると
  キーボードフォーカスが正しく戻るようになりました。GH-11320
- macOS: フルスクリーンでタブタイトルの名前変更時のクリック判定を修正し、
  ネイティブフルスクリーンでダブルクリックしてタブ名を変更できるようになりました。GH-11353
- macOS: 分割がない場合、ネイティブフルスクリーンで分割のドラッグハンドルが
  表示されなくなりました。GH-11376
- macOS: 分割のドラッグハンドルは、マウスポインターが近くにある場合にのみ
  表示されるようになりました。GH-11379
- macOS: Ghostty のキーバインドが再び macOS のシステムキーバインドより
  優先されるようになり、`super+h` などのキーを再び割り当てられるようになりました。
  GH-11396 GH-11403
- macOS: ターミナルにワンタイムコードの自動入力が表示されなくなりました。GH-11351
- macOS: 最初のウィンドウの配置、ウィンドウをずらして重ねる動作、
  分割をドラッグして新規ウィンドウにしたときの配置を改善しました。GH-11421 GH-11426 GH-11429
- macOS: AppleScript のタブ選択コマンドが、意図せずアプリケーションを
  アクティブにすることがなくなりました。GH-11459

### GTK (Linux, FreeBSD) {/* #gtk-(linux-freebsd) */}

- GTK: `+new-window` を `-e` と組み合わせて使うときに、推定された
  `--working-directory` を正しく扱うようになりました。GH-11357 GH-11356
- Snap: Ghostty が Snap ランチャーの `LD_LIBRARY_PATH` を子プロセスに
  引き継がなくなり、起動されたアプリケーションで実行時の競合が起きるのを
  防げるようになりました。GH-11431

### パッケージメンテナー向けの変更 {/* #changes-for-package-maintainers */}

このリリースにパッケージメンテナー向けの変更はありません。

## ロードマップ {/* #roadmap */}

1.3.x のほかのリグレッションや問題も引き続き調査しており、いずれ 1.3.2 を
リリースする見込みです。リリース当日の重大なバグへの対応を優先した 1.3.1 の
ときよりは、少し間を空けてリリースする予定です。
