## セキュリティ {/* #security */}

- [GHSA-5hcq-3j4q-4v6p](https://github.com/ghostty-org/ghostty/security/advisories/GHSA-5hcq-3j4q-4v6p)。Ghostty がウィンドウタイトルのシーケンスを適切に処理せず、任意のコード実行につながる可能性があった脆弱性を修正しました（ユーザー操作が必要です）。

- [GHSA-hfg5-8q2c-crhc](https://github.com/ghostty-org/ghostty/security/advisories/GHSA-hfg5-8q2c-crhc)。従来、`write_*_file` キーバインドアクションで作成したファイルは既定でモード `0644` となり、ローカルのすべてのユーザーが読み取れました。意図しないアクセスを防ぐため、既定のモードを `0600` に変更しました。

## 主な変更点 {/* #highlights */}

### 既定の設定ファイル {/* #default-configuration-file */}

PR: [#3460](https://github.com/ghostty-org/ghostty/pull/3460)

空でない設定ファイルが見つからない場合、Ghostty の起動時に既定の設定ファイルを作成するようになりました。[設定不要という方針](/docs/config#zero-configuration-philosophy) に沿って、既定の設定ファイルにはコメントしかありません。そのコメントにはファイルの場所や構文、ドキュメントの情報が記載されています。

1.0.0 のリリースでは、設定ファイルがどこにあるのか、どう編集するのか、どんな設定項目が使えるのかが分かりにくいという声が多くありました。今回の変更は、Ghostty の設定方法を分かりやすくするためのものです。

### ビットマップフォントのサポート {/* #bitmap-font-support */}

PR: [#4115](https://github.com/ghostty-org/ghostty/pull/4115) (CoreText),
[#3837](https://github.com/ghostty-org/ghostty/pull/3837)（FreeType）

macOS と Linux の両方で、Ghostty がビットマップフォントに対応しました。フォントは引き続き TrueType 形式である必要がありますが、各グリフをアウトラインではなくビットマップで収録したものを使えます。

### macOS: 「設定」の改善 {/* #macos:-"settings"-improvements */}

PR: [#4004](https://github.com/ghostty-org/ghostty/pull/4004)

「設定」メニュー項目（`open_config` キーバインドアクション）をいくつか改善しました。

まず、空でない設定ファイルがあれば、最初に該当するファイルを探して開くようになりました。以前は AppSupport 側の設定が存在していても、常に XDG 側の設定パスを最初に開いていました。実際には AppSupport 側の設定が XDG 側より優先されるため、混乱の原因になっていました。今後は AppSupport 側のパスがあればそれを開き、なければ XDG 側のパスを開きます。

次に、どちらのパスも存在しない場合は、XDG より AppSupport のパスを正しく優先するようになりました。macOS では AppSupport のパスがほかのすべてのパスよりも優先されるため、これは重要です。

最後に、`open` コマンドに `-t` フラグを渡し、設定ファイルをテキストエディターで開くようにしました。

<Note>
今後の更新で、設定ファイルを `$EDITOR` で開けるようにする予定です。さらに別の更新で、GUI から設定ファイルを編集できるようにする予定です。
</Note>

## 改善 {/* #improvements */}

- 色の値に、`#ABC` などの短縮形の 16 進表記を指定できるようになりました。[#4111](https://github.com/ghostty-org/ghostty/issues/4111)
- `confirm-close-surface` を `always` にすると、ウィンドウを閉じるときに確認ダイアログを必ず表示するようになりました。[#3700](https://github.com/ghostty-org/ghostty/pull/3700)
- macOS: Spotlight 検索のメタデータに「terminal」キーワードを追加しました。[#3745](https://github.com/ghostty-org/ghostty/pull/3745)
- GTK: `window-titlebar-foreground` と `window-titlebar-background` の設定オプションを追加しました。[#3806](https://github.com/ghostty-org/ghostty/pull/3806)
- 同梱の iTerm2 カラースキームを [e030599a](https://github.com/mbadolato/iTerm2-Color-Schemes/tree/e030599a6a6e19fcd1ea047c7714021170129d56) に更新しました。

## バグ修正 {/* #bug-fixes */}

[対応済みの Issue の全一覧（GitHub）](https://github.com/ghostty-org/ghostty/milestone/2?closed=1)。

- キーに対応するトリガーを持つキーバインドは、Unicode のトリガーではなく、配列に従って解釈されたキーとして扱うようにしました。これにより、`cmd+one` に加えて `cmd+1` が使えるようになり、`cmd+.` と `cmd+period` が同じ意味になります。[#4147](https://github.com/ghostty-org/ghostty/pull/4147)
- `write_selection_file` が空の内容を書き出す場合があった問題を修正しました。[#4078](https://github.com/ghostty-org/ghostty/pull/4078)
- TUI アプリ内のハイパーリンクがより安定して動作するようになりました。[#3903](https://github.com/ghostty-org/ghostty/pull/3903)
- 設定を再読み込みしても、OSC 10/11/12 による設定が上書きされなくなりました。[#3228](https://github.com/ghostty-org/ghostty/pull/3228)
- `scrollback-limit` 設定で 32 ビットを超える数値を指定できるようになりました。[#3906](https://github.com/ghostty-org/ghostty/pull/3906)
- macOS と Linux の両方で、`background-opacity` の問題を修正しました。[#3347](https://github.com/ghostty-org/ghostty/pull/3347)
- コマンドラインで `--font-family=""` を指定するとクラッシュすることがある問題を修正しました。[#4151](https://github.com/ghostty-org/ghostty/pull/4151)
- VT: 更新された仕様に従い、OSC 10/11/12 に対してモード 2031 の DSR 応答を送らなくなりました。[#3994](https://github.com/ghostty-org/ghostty/pull/3994)
- VT: ダイレクトカラーの解析で起きる例外的なケースを修正しました。[#4216](https://github.com/ghostty-org/ghostty/pull/4216)
- Bash: シェル統合が `sudo` のエイリアスと組み合わせても、より適切に動作するようになりました。[#4080](https://github.com/ghostty-org/ghostty/pull/4080)

## パッケージメンテナー向けの変更 {/* #changes-for-package-maintainers */}

- Ghostty のソース tarball の名前が `ghostty-source.tar.gz` から `ghostty-${VERSION}.tar.gz` に変わり、展開先のディレクトリ名も `ghostty-source` から `ghostty-${VERSION}` に変わりました。一般的なソース tarball の命名慣行に合わせるための変更です。この変更を `PACKAGING.md` に反映しました。[#3490](https://github.com/ghostty-org/ghostty/pull/3490)
- `DESTDIR` が `PACKAGING.md` の記載どおりに動作するようになりました。[#3426](https://github.com/ghostty-org/ghostty/pull/3426)

## 既知の問題 {/* #known-issues */}

Ghostty 1.0.1 にはまだ多くの既知の問題がありますが、一般的な用途や業務用途で使える安定性に達していると考えています。

これらの問題の優先順位付けと解決に取り組んでいます。休暇を終えて仕事に戻る方が多いことも踏まえ、今回のリリースでは私たちが最も重大と判断した問題に対処しました。既知の問題や新たに見つかった問題については、GitHub の Discussions と Issue を参照してください。

## ロードマップ {/* #roadmap */}

近いうちに 1.0.2 をリリースする予定です。パッチリリースを頻繁に出すつもりはありませんが、初の一般公開以降に見つかった重要な問題のうち、できるだけ早く解決すべきものがまだいくつか残っています。

1.0.2 に向けて主に調査しているのは、特に US 配列以外でのキーボード入力の問題、xterm との互換性の問題、Linux と macOS の両方での GUI の問題です。

長期的には、大きなリリースのあとにパッチリリースを 1 回か 2 回だけ行い、次の大きなリリースに向けて数か月を開発に充てる方針です。[^1] この流れであれば、パッケージメンテナーは過度な手戻りなくリリースに追従し、配布チャネルに載せられます。Ghostty のメンテナーも、新機能や改善に注力できます。

[^1]: ただし、すぐに対処が必要な重大な問題やセキュリティアドバイザリがある場合は除きます。
