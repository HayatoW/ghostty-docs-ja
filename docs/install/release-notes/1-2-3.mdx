Ghostty 1.2.3 には、**6 人のコントリビューター**による**2 週間分の作業**が
**27 件のコミット**として含まれています。主に 1.2.x 系列で発生した問題を
修正するためのパッチリリースです。

<Important>
  このリリースには、すべてのプラットフォームで発生しうるデッドロックの重大な修正が
  含まれています。以前の 1.2.x バージョンをご利用の方は、できるだけ早くこの
  バージョンにアップグレードすることを強くおすすめします。
</Important>

## ハイライト {/* #highlights */}

### macOS のタイトルバータブの改善 {/* #macos-titlebar-tabs-improvements */}

関連 PR: GH-9090 GH-9163 GH-9168 GH-1787 GH-1813 GH-1945 GH-8612

Ghostty 1.2.3 では `macos-titlebar-style = tabs` をめぐる複数の問題を修正しました。
中には 1.0 より前から残っていた問題も多数あります。Tahoe ではタブバーが大きく
変わったため、この設定に関連する Tahoe (macOS 26) 固有のバグも複数修正しました。

変更の概要です。

- タブを表示するタイトルバースタイルで、タイトルの位置がずれたり見切れたりする問題を修正しました。
- タイトルバータブが有効な場合のフルスクリーンモードで、タイトルバーの色を修正しました。
- テーマを変更するとタイトルバーのスタイルが失われる問題を修正しました。
- フルスクリーンでタブを表示するタイトルバースタイルを使うと、途切れたタイトルが
  左上隅に表示される問題を修正しました。
- macOS 26 のネイティブフルスクリーンとタイトルバータブを組み合わせた場合の動作を改善しました。

### フォント描画の改善 {/* #font-rendering-improvements */}

関連 PR: GH-9142 GH-9152 GH-9160

Ghostty 1.2.3 でも引き続き、1.2.0 で刷新したフォント描画システムにいくつもの
改善を加えました。Ghostty 1.2.3 の変更は、主に Nerd Fonts などのアイコングリフを
対象としています。Ghostty 1.2.3 では、どのような状況でもアイコンがより適切な
大きさで表示されるはずです。

これにより、特に 1.2.0 でのレンダラー刷新に起因する問題を含め、現時点で
判明しているフォントの*描画*に関する問題はすべて解決されます。
フォントに関する既知の問題はほかにもありますが、いずれも Ghostty 1.2 より前から
存在するか、フォント描画ではなく検索、読み込み、シェーピングなどに関するものです。

## 変更履歴の全文 {/* #full-changelog */}

[GitHub でクローズ済みの Issue の全一覧](https://github.com/ghostty-org/ghostty/milestone/10?closed=1)。

各セクションでは、なるべく改善を先に、バグ修正を後に記載しています。

- フォント: 特にアイコングリフに関するさまざまな特殊ケースに対応するため、
  多数の微調整を行いました。GH-9076 GH-9142 GH-9160 GH-9152
- ターミナル: 選択時に単語の区切りとして扱う文字にセミコロンを追加しました。GH-9069
- 入力: modify other keys のモード 2 では、処理済みかどうかにかかわらずすべての
  修飾キーを使うようにしました。これにより、tmux や modify other keys の
  モード 2 を使うほかのターミナルプログラムで、Shift と組み合わせた修飾キーが
  機能しなくなるエンコードの誤りを修正しました。GH-9289
- 色の変更や問い合わせを多数発行するプログラムが Ghostty のハングを引き起こす
  デッドロックを修正しました。GH-9224
- ビューポートの外でスクロールする際、スクロールタイマーがすでに動作中なら
  新たに起動しないようにし、リソースリークを修正しました。GH-9195
- プライマリ画面か代替画面の一方でスクロールを開始し、ターミナルプログラムが
  画面を切り替えた後もスクロールを続けると発生しうるメモリ破損を修正しました。GH-9223
- レンダラー: 一部の条件で描画が乱れる問題を修正しました。GH-9252
- シェル統合: `ssh-terminfo` が IPv6 アドレスを正しくキャッシュするようになりました。GH-9251 GH-9281
- シェル統合: fish の vi モードでカーソル統合が機能するようになりました。GH-9157
- シェル統合: ユニバーサル変数 `fish_user_paths` を更新しなくなりました。GH-9273

### macOS {/* #macos */}

- macOS: クイックターミナルのサイズが画面ごとに正しく記憶されるようになりました。GH-9256
- macOS: `goto_split` で方向を指定した場合も `performable:` キーバインドで動作するようになりました。
  GH-9283 GH-9284
- macOS: `window-position-x/y` が `window-width/height` と組み合わせても正しく機能します。GH-9313
- macOS: 安全でない長いテキストを貼り付けると UI がハングする問題を修正しました。GH-9322 GH-9324
- macOS: `macos-titlebar-style=tabs` に関する複数の問題を修正しました。GH-1787
  GH-1813 GH-1945 GH-8612 GH-9090 GH-9163
- macOS: New Tab（新規タブ）アクションで、ウィンドウではなくタブを開くべき場合に
  確実にタブが開くようになりました。GH-9124
- macOS: Cocoa API が nil ロケールを返す場合のクラッシュを修正しました。GH-9290

### GTK (Linux, FreeBSD) {/* #gtk-(linux-freebsd) */}

- GTK: `title` が設定されている場合、ウィンドウタイトルがすぐに正しく設定されます。GH-9120
- GTK: クイックターミナルの自動非表示が正しく機能するようになりました。GH-9145 GH-9139

### パッケージメンテナー向けの変更 {/* #changes-for-package-maintainers */}

- Ghostty をテーマの同梱なしでビルドできるように、新しいビルドオプション
  `-Demit-themes`（デフォルトは true）を追加しました。上流の依存関係に
  ライセンス上の問題があるかもしれないことを懸念するパッケージ作成者のために
  追加したものです。この点は引き続き詳しく調査していますが、懸念がある場合に
  テーマそのものを含めずに済むようにする短期的な対策です。GH-9288

## ロードマップ {/* #roadmap */}

重大な問題が見つからない限り、1.2.x の追加リリースは予定していません。
1.2.x 系列はすでに非常に安定しており、残っていた大きな問題は 1.2.3 で解決したと考えています。

もちろん、Ghostty にバグがないというわけではありません。今後もバグ修正や機能改善を
続けますが、重大なバグでない限り、それらのリリースは Ghostty 1.3.0 まで見送ります。
