Ghostty 1.1.1 には、**13 人の貢献者**による **125 件のコミット**にわたる、**2 週間分の成果**が含まれています。今回は、1.1.0 で生じたリグレッションやバグの修正に注力しました。既存の機能に対する便利な改善もいくつか盛り込んでいます。

<Important>
macOS 版 Ghostty 1.1.1 で、Neovim や Fish 4.0 など Kitty キーボードプロトコルを使うプログラムで、Control キーを併用した入力が正しく動作しない重大なリグレッションが見つかりました。この問題は [1.1.2](/docs/install/release-notes/1-1-2) で修正済みです。
</Important>

## 主な変更点 {/* #highlights */}

### Linux の X11 でのサーバー側ウィンドウ装飾（SSD） {/* #server-side-decorations-(ssd)-on-linux-x11 */}

PR:
[#5533](https://github.com/ghostty-org/ghostty/pull/5533)

Ghostty 1.1.0 で [Linux の Wayland コンポジター向けのサーバー側ウィンドウ装飾（SSD）](/docs/install/release-notes/1-1-0#server-side-decorations-(ssd)-on-linux) に対応しました。これにより、より多くのデスクトップ環境で、見た目と使い勝手がネイティブアプリに近づきます。ただし、X11 では動作していませんでした。

Ghostty 1.1.1 では、`window-decoration = server` のときに X11 でも SSD を使えるようになりました。X11 には、SSD とクライアント側ウィンドウ装飾（CSD）のどちらを優先するかを伝える標準の手段がありません。そのため、X11 で SSD を使うには `server` を明示する必要があり、`auto` では動作しません。

### 入力メソッド（IME）のさらなる改善 {/* #continued-input-method-editor-(ime)-improvements */}

PR:
[#5550](https://github.com/ghostty-org/ghostty/pull/5550)
[#5448](https://github.com/ghostty-org/ghostty/pull/5448)

Ghostty 1.1.0 では IME 対応の改善に力を入れましたが、皮肉にも入力メソッドが有効でない場合（GTK の「simple」入力メソッド）の入力が壊れていました。1.1.1 では修正済みです。1.1.0 では `ibus` または `fcitx` をインストールすることで回避できましたが、今はその必要がなく、「simple」入力メソッドが意図どおりに動作します。

また macOS では、IME 対応の改善により、一部のキーボード配列で `ctrl+c` などの制御文字が入力できなくなっていました。これも 1.1.1 で修正しました。

### macOS: Intel 搭載 Mac の GPU 描画の改善 {/* #macos:-renderer-improvements-for-intel-gpus */}

PR:
[#5625](https://github.com/ghostty-org/ghostty/pull/5625),
[#5652](https://github.com/ghostty-org/ghostty/pull/5652)

macOS でディスクリート GPU を使用すると、Ghostty が未定義の動作を引き起こしていました。Apple Silicon の Mac はすべて内蔵 GPU を搭載しており、Ghostty は省電力のため、内蔵 GPU があれば常にそちらを優先します。そのため、実際に影響を受けたのは Intel 搭載 Mac のみです。

この未定義の動作は問題なく見えることもあれば、描画の乱れなど視覚的な異常を引き起こすこともありました。今回、ディスクリート GPU を正しく検出し、適切な API と処理を使用して、未定義の動作を回避するようにしました。

## 変更の全一覧 {/* #full-list */}

[対応済みの Issue の全一覧（GitHub）](https://github.com/ghostty-org/ghostty/milestone/4?closed=1)。

各節では、できる限りバグ修正より先に改善を掲載しています。

- `goto_split` と `goto_tab` が `performable:` キーバインドプレフィックスで正しく動作するようになりました。[#5644](https://github.com/ghostty-org/ghostty/issues/5644)
- `+list-actions` CLI コマンドで、ドキュメントのないアクションも一覧に含めるようになりました。[#4958](https://github.com/ghostty-org/ghostty/issues/4958)
- ターミナルインスペクターのターミナル入出力ウィンドウを、キーボードで操作できるようになりました。[#3909](https://github.com/ghostty-org/ghostty/issues/3909)
- 画面に Kitty グラフィックスが表示されている状態でターミナルをリセットすると、クラッシュすることがある問題を修正しました。[#5693](https://github.com/ghostty-org/ghostty/issues/5693)
- 非常に大きな OSC 8 ハイパーリンクでクラッシュすることがある問題を修正しました。ほかにも同じクラッシュに至るケースがあると考えられますが、同種の原因はまとめて解消しました。[#5666](https://github.com/ghostty-org/ghostty/issues/5666)
- カーソルの色が背景色と同じ場合に、カーソルの下の文字が見えなくなる問題を修正しました。[#5570](https://github.com/ghostty-org/ghostty/issues/5570)
- ファイルではないテーマを読み込もうとするとクラッシュすることがある問題を修正しました。[#5632](https://github.com/ghostty-org/ghostty/issues/5632)
- iTerm2 のカラーテーマを [db227d159](https://github.com/mbadolato/iTerm2-Color-Schemes/tree/db227d159adc265818f2e898da0f70ef8d7b580e) に更新しました。[#5511](https://github.com/ghostty-org/ghostty/pull/5511)

### macOS {/* #macos */}

- macOS: アーティストが手がけた新しい代替アイコンをいくつか追加しました。`macos-icon` 設定で選べます。[#5696](https://github.com/ghostty-org/ghostty/issues/5696)
- macOS: ほかの macOS のネイティブアプリに合わせて、起動時に最後にフォーカスされていたウィンドウの位置にウィンドウを配置します。[#5529](https://github.com/ghostty-org/ghostty/issues/5529)
- macOS: 非表示でも、閉じる確認が必要なクイックターミナルが動作中なら、確認を表示するようになりました。[#5450](https://github.com/ghostty-org/ghostty/issues/5450)
- macOS: 一部のキーボード配列で制御文字が機能しない問題を修正しました。[#5448](https://github.com/ghostty-org/ghostty/issues/5448)
- macOS: `move_tab` キーバインドを実行したときの描画のちらつきを修正しました。[#5729](https://github.com/ghostty-org/ghostty/issues/5729)
- macOS: `toggle_visibility` をグローバルキーバインドから実行した場合に、正しいタブにフォーカスが戻るようになりました。[#5692](https://github.com/ghostty-org/ghostty/issues/5692)
- macOS: `cmd+backtick` など、Command キーを併用した一部の入力で、修飾されていない文字がターミナルに送られてしまう問題を修正しました。[#5558](https://github.com/ghostty-org/ghostty/issues/5558)
- macOS: ウィンドウがネイティブのフルスクリーン表示の間、`toggle_visibility` は何もしなくなりました。以前はウィンドウがフォーカスを失っていました。[#5472](https://github.com/ghostty-org/ghostty/issues/5472)
- macOS: ディスクリート GPU での未定義の動作を修正しました。[#5625](https://github.com/ghostty-org/ghostty/issues/5625)
- macOS: セキュリティ上の問題を修正するため、依存している Sparkle を 2.6.4 に更新しました。[#5598](https://github.com/ghostty-org/ghostty/issues/5598)

### Linux（GTK） {/* #linux-(gtk) */}

- GTK: サーバー側ウィンドウ装飾（SSD）が X11 でも動作するようになりました。[#5533](https://github.com/ghostty-org/ghostty/pull/5533)
- GTK: `WINDOWID` 環境変数を X11 のウィンドウ ID に設定します。[#5650](https://github.com/ghostty-org/ghostty/issues/5650)
- GTK: 一部の状況でコンテキストメニューが誤った位置に表示される問題を修正しました。[#5710](https://github.com/ghostty-org/ghostty/issues/5710)
- GTK: 「simple」入力メソッドが正しく動作するようになりました。[#5550](https://github.com/ghostty-org/ghostty/pull/5550)

- GTK: Nautilus との統合で、正しい名前のファイルを使うようになりました。[#5469](https://github.com/ghostty-org/ghostty/pull/5469)

### パッケージメンテナー向けの変更 {/* #changes-for-package-maintainers */}

- Zig の依存関係に [`zig-gobject`](https://github.com/ianprime0509/zig-gobject) が加わりました。ライセンスは 0BSD です。この依存関係の追加で、既存の Ghostty のパッケージ作成手順が変わることはありません。

## ロードマップ {/* #roadmap */}

このリリースの時点では、後続のパッチリリースは予定していません。残っているバグは軽微で、将来のより大きなリリースである 1.2.0 で対処できると考えています。重大な問題が生じた場合に備え、引き続き Issue と PR を確認します。

今後は 1.2.0 のリリースに注力します。より重要な変更と機能を含む、大きなリリースになります。リリース時期は未定ですが、おそらく数か月先です。

1.2.0 で予定している Linux 向けの大きな互換性変更の一つは、`libadwaita` の必須化です。この方針は 1.1.0 のリリース時に発表し、問題があればフィードバックを寄せていただくようお願いしています。フィードバックを送る前に、[この変更の詳細をよくお読みください](/docs/install/release-notes/1-1-0#gtk:-forcing-a-dependency-on-libadwaita)。
