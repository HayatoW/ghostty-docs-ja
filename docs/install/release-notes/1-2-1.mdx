Ghostty 1.2.1 には、**13 人の貢献者**による **62 件のコミット**にわたる、**2 週間分の成果**が含まれています。主に 1.2.0 で生じた問題を修正するパッチリリースです。いくつかの小さな改善も含まれています。

## 主な変更点 {/* #highlights */}

### フォント描画の改善 {/* #font-rendering-improvements */}

PRs: GH-8563 GH-8580 GH-8738 GH-8720 GH-8847

Ghostty 1.2.0 ではフォント描画システムを大幅に刷新しました。大きな変更にはつきものですが、テストでは見つからなかった問題がいくつか報告されました。Ghostty 1.2.1 ではその多くに対処しています。

変更の概要は以下のとおりです。

- Nerd Font のアイコンを大きくし、アイコン同士の見かけのサイズを揃え、セルの領域をより有効に使うようにしました。1 セルより幅が広いアイコンは、複数のセルにまたがって中央揃えにするのではなく、左揃えにします。
- 幅の広い主フォントを使っても、CJK の文字が大きくなりすぎなくなりました。ASCII 文字全体の境界ボックスを測り、IC 幅（表意文字の幅）の上限とします。
- グリフのサイズ制約を太さの調整と中央揃えより先に適用するようにしました。これにより、フォントサイズ、太さの調整量、ディスプレイの DPI に関係なく、アイコンのサイズと位置が一貫します。
- Nerd Font のパッチの抽出処理で、コードポイントのオフセットの問題により規則が誤ったグリフに適用されるバグと、無関係なパッチセットが取り込まれるバグを修正しました。
- FreeType のグリフ測定を改善し、描画時と同じヒンティングを使って測定するようにしました。

### シェル統合で `PATH` に `ghostty` を追加 {/* #shell-integration-adds-ghostty-to-path */}

PR: GH-8976

シェル統合が `GHOSTTY_BIN_DIR` を PATH に自動で追加するようになりました。これにより、多くのシェルで追加設定なしに `ghostty` バイナリが使えます。

Ghostty は以前から、シェルを実行する前に `ghostty` のあるディレクトリを PATH に追加しますが、多くのシェル設定は PATH をリセットします。今回の変更では、シェル統合スクリプトでも追加し、シェルで `ghostty` を利用できる可能性を高めます。

Bash、Zsh、fish、Elvish に対応しています。

### 高精度スクロールデバイスのスクロール倍率 {/* #mouse-scroll-multiplier-for-precision-scrolling-devices */}

PR: GH-8927

`mouse-scroll-multiplier` 設定が、Apple のトラックパッドなどの高精度スクロールデバイスに対応しました。段階的なスクロール（マウスホイール）と高精度スクロール（トラックパッド）の倍率を個別に調整できます。入力デバイスが変わっても、大量のスクロールバックを滑らかに、意図どおりに移動できます。

設定例:

```
# Apply the same multiplier to both precision and discrete
mouse-scroll-multiplier = 3

# Apply different multipliers (order doesn't matter)
mouse-scroll-multiplier = precision:0.1,discrete:3

# Apply only to precision, use default for discrete
mouse-scroll-multiplier = precision:2
```

高精度スクロールの倍率の既定値は `0.1` です。段階的スクロールの倍率の既定値は引き続き `1` です。

## ロードマップ {/* #roadmap */}

1.2.0 と 1.2.1 の変更で生じた小さな問題に引き続き対処するため、いずれ 1.2.2 をリリースする可能性が高いと考えています。リリースする場合は、すぐではなく数か月先のリリースサイクルの途中になる見込みです。

現時点で 1.2.x 系は非常に安定しており、新たなバグ修正リリースを急ぐ必要はないと考えています。今回のリリースには非常に好意的な反響があり、皆さんが新機能を楽しんでいることをうれしく思います。

全体の計画は、[1.2.0 のリリースノート](/docs/install/release-notes/1-2-0#roadmap) のロードマップを参照してください。
