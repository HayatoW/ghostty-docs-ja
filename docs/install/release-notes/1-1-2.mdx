---
title: Ghostty 1.1.2
description: |-
  Ghostty 1.1.2（2025 年 2 月 13 日リリース）のリリースノートです。
---

Ghostty 1.1.2 は、macOS 版 1.1.1 で生じた重大なリグレッションに対する緊急修正版です。この問題により、Neovim や Fish 4.0 などの Kitty キーボードプロトコルを使うプログラムで、Control キーを併用した入力が正しく動作しなくなっていました。

このバージョンは 1.1.1 と同じ日にリリースされました。[1.1.1 のリリースノート](/docs/install/release-notes/1-1-1) も参照してください。

<Note>
**このリリースに Linux 向けの変更はありません。** パッケージメンテナーにとって都合がよければ、このリリースを見送り、次のリリースまで 1.1.1 を使い続けられます。
</Note>
