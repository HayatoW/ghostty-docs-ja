---
title: ビルド済み Ghostty バイナリとパッケージ
description: |-
  ビルド済みバイナリやパッケージをダウンロードして実行すれば、
  手動でビルドせずに Ghostty をインストールできます。
---

Ghostty プロジェクトがビルド済みバイナリを公式に配布しているのは macOS のみです。
Linux などのほかのプラットフォームでは、ディストリビューションのメンテナーやコミュニティメンバーが、
幅広いユーザーに向けた Ghostty のビルド、テスト、配布を担っています。

Ghostty のメンテナーが特定のディストリビューション向けのパッケージ保守にも関わることがありますが、
それは Ghostty プロジェクト全体としての推奨を意味するものではありません。

## macOS {/* #macos */}

公式の macOS バイナリは Ghostty プロジェクトが提供しており、[ダウンロードページ](/download)から入手できます。

これらのバイナリは Ghostty プロジェクトによって署名・公証されています。
インストールするには、`.dmg` ファイルをダウンロードして開き、Ghostty アプリケーションをアプリケーションフォルダにドラッグします。
一般的な macOS アプリケーションの多くと同じ手順です。

### Homebrew {/* #homebrew */}

Ghostty コミュニティが保守する [Homebrew cask](https://formulae.brew.sh/cask/ghostty) も利用できます。
公式の `.dmg` を再パッケージ化しただけのものなので、公式バイナリ自体と同等のセキュリティが期待できます。

```sh
brew install --cask ghostty
```

### Nix（macOS バイナリ） {/* #nix-(macos-binary) */}

Nixpkgs では、公式の `.dmg` を再パッケージ化した Ghostty が `ghostty-bin` というパッケージ名で利用できます。
[Linux 上の Nix で利用できる](#nix) GTK アプリの `ghostty` と混同しないようにしてください。

<Note>

残念ながら、現在 Nix では macOS 上で Ghostty をソースからコンパイルできません。

これは、Swift 6 への対応や、自由に利用でき、自動化・再現可能な xcodebuild の代替手段など、
必要なエコシステムのサポートが Nixpkgs にまだ揃っていないためです。
将来的には、`ghostty-bin` を `ghostty` に統合し、macOS アプリと GTK アプリの両方をソースからビルドして提供することを検討するかもしれません。

</Note>

nix-darwin ユーザーは、通常の方法でシステム全体または特定のユーザー向けに Ghostty をインストールできます。

```nix
{
  pkgs,
}:
{
  # Systemwide install
  environment.systemPackages = [
    pkgs.ghostty-bin
  ];
  
  # Install for a specific user
  users.users.somebody.packages = [
    pkgs.ghostty-bin
  ];
}
```

## Linux {/* #linux */}

Ghostty は多くの Linux ディストリビューションの標準リポジトリで利用できます。
これらのパッケージはすべて各ディストリビューション自身がビルド、テスト、検証しており、Ghostty プロジェクトとは関係がありません。

特定のディストリビューションでの Ghostty のインストールや実行に支援が必要な場合、
またはパッケージに関する質問がある場合は、**お使いのディストリビューションの Ghostty パッケージメンテナーにお問い合わせください**。
Ghostty 自体の問題だと判明すれば、メンテナーが代わりに issue を作成します。

お使いのディストリビューションがここにない場合は、[コミュニティがビルドしたバイナリパッケージ](#linux-(community-binaries))に
インストール可能なものがあるか確認してください。なければ、[Ghostty をソースからビルド](/docs/install/build)する必要があります。

<Tip>
  **お使いのプラットフォーム向けのパッケージ作成に興味がありますか？**
  [パッケージ化ガイド](https://github.com/ghostty-org/ghostty/blob/main/PACKAGING.md)を参照してください。
  支援が必要なら、お気軽に issue を作成してください。パッケージが完成したら、このページに追加するプルリクエストをお送りください！
</Tip>

### Alpine Linux {/* #alpine-linux */}

Ghostty は、Alpine Linux 公式の [testing リポジトリ](https://pkgs.alpinelinux.org/package/edge/testing/x86_64/ghostty)で利用できます。

```sh
apk add ghostty
```

### Arch Linux {/* #arch-linux */}

Ghostty の最新のタグ付きリリースは、Arch Linux の `[extra]` リポジトリで
[`ghostty`](https://archlinux.org/packages/extra/x86_64/ghostty/) として利用できます。

```sh
pacman -S ghostty
```

プレリリースビルドも、AUR の `ghostty-git` として利用できます。
詳しくは[「プレリリースビルド」](/docs/install/pre#aur)を参照してください。

### conda-forge {/* #conda-forge */}

Ghostty は、クロスプラットフォームのコミュニティ主導のパッケージシステム [`conda-forge`](https://conda-forge.org) で利用できます。
[`pixi`](https://pixi.prefix.dev/latest/#installation) でインストールできます。

```sh
pixi global install ghostty
```

### Gentoo {/* #gentoo */}

Ghostty は Gentoo の公式リポジトリで利用できます。

```sh
emerge -av ghostty
```

### Nix {/* #nix */}

Linux では、Nix で Ghostty をインストールする主な方法は 2 つあります。
Nixpkgs のメンテナーチームが保守する [Nixpkgs] の `ghostty` パッケージか、
Ghostty プロジェクトが直接保守する Ghostty のソースリポジトリ内の Flake を使います。

一般的なユーザーの多くにとって、Nixpkgs のパッケージが最も簡単な選択肢です。
一方、Flake では、より上級のユーザーが開発ブランチの特定のバージョン（「tip リリース」）を固定してインストールし、最先端の機能を利用できます。
そのため、このページでは **Nixpkgs のパッケージのみを説明します**。
Flake の情報は、「プレリリースビルド」ページの[専用セクション](/docs/install/pre#nix-flake)を参照してください。

[Nixpkgs]: https://search.nixos.org/packages?from=0&size=50&sort=relevance&type=packages&query=ghostty

<Note>

Nixpkgs の `ghostty` パッケージを、macOS 用に公式の `.dmg` を再パッケージ化した
[`ghostty-bin`](#nix-(macos-binary)) と混同しないでください。

</Note>

#### NixOS {/* #nixos */}

NixOS ユーザーは、通常の方法でシステム全体または特定のユーザー向けに Ghostty をインストールできます。

```nix
{
  pkgs,
}:
{
  # Systemwide install
  environment.systemPackages = [
    pkgs.ghostty
  ];
  
  # Install for a specific user
  users.users.somebody.packages = [
    pkgs.ghostty
  ];
}
```

`nix run` や `nix-shell` を使い、インストールせずに Ghostty を試すことも問題なくできるはずです。

```sh
nix run nixpkgs#ghostty
nix-shell -p ghostty --run ghostty
```

#### ほかのディストリビューション上の Nix {/* #nix-on-other-distros */}

<Warning>

NixOS 以外のシステムで Nix を使って Ghostty を実行する場合、追加設定なしでは**起動に失敗します**。
Nixpkgs 向けにコンパイルされたグラフィカルプログラムは、従来のディストリビューションとは異なる場所に OpenGL ドライバーがあることを想定しており、
手動で対処しなければ見つけられないためです。

</Warning>

対処方法はいくつかあります。Home Manager を使っている場合は、
[システムを変更][`modify your system`]してグラフィックスドライバーを NixOS と同じ場所に置くか、
[プログラムをラップ][`wrap your programs`]して正しいドライバーを参照させられます。

NixOS も Home Manager も使っていない場合は、[`nixGL`]、[`nix-gl-host`]、[`nix-system-graphics`] などの
独立したラッパーツールも使えます。いずれも、少しずつ異なる方法で同じ目的を達成します。

[`modify your system`]: https://nix-community.github.io/home-manager/index.xhtml#sec-usage-gpu-sudo
[`wrap your programs`]: https://nix-community.github.io/home-manager/index.xhtml#sec-usage-gpu-nosudo
[`nixGL`]: https://github.com/nix-community/nixGL
[`nix-gl-host`]: https://github.com/numtide/nix-gl-host
[`nix-system-graphics`]: https://github.com/soupglasses/nix-system-graphics

それ以外の手順は、NixOS とほぼ同じです。

### openSUSE {/* #opensuse */}

Ghostty は openSUSE 公式の `repo-oss` リポジトリから利用できます。

```sh
sudo zypper in ghostty
```

必要に応じて、パッケージの詳細を確認できます。

```sh
sudo zypper info ghostty
```

<summary>過去に、Zig のバージョンの不一致により <code>ghostty</code> が公式リポジトリから削除されたことがあります。<strong>インストールコマンドが動作しない場合は、こちらを参照してください。</strong></summary>

#### 公式リポジトリからの削除: 2025 年末から 2026 年 3 月頃まで {/* #removed-from-official-repo:-end-of-2025-to-~march-2026 */}

> この注記は、再発した場合にユーザーに関連情報を提供できるよう、今後の参考として残しています。
> 現時点（2026 年 7 月）では、Ghostty は[公式リポジトリ](https://build.opensuse.org/package/show/openSUSE%3AFactory/ghostty)に戻っているはずです。

---

openSUSE は、パッケージが特定バージョンの Zig に依存することを認めていないため、Ghostty を公式リポジトリから[削除しました][opensuse-dropped]。
Zig の新しいリリースのほぼすべてに破壊的変更が含まれ、以前の Zig 向けのソフトウェアをコンパイルできなくなるため、これは Ghostty にとって*重大な*問題です。

[opensuse-dropped]: https://lists.opensuse.org/archives/list/factory@lists.opensuse.org/thread/BMZTZ2DCNWXARP5UD7MECR6PCWOTKR5G/#BMZTZ2DCNWXARP5UD7MECR6PCWOTKR5G

openSUSE ユーザーは、代わりに Ghostty をソースからビルドするか、
コミュニティが保守するサードパーティーのリポジトリからインストールしてみてください。

</details>

### Snap {/* #snap */}

Ghostty は Snap Store で [`ghostty`](https://snapcraft.io/ghostty) として利用できます。

```sh
snap install ghostty --classic
```

<Note>
Snapcraft 上の Snap は現在外部のメンテナーが保守していますが、Snap 自体は Ghostty 独自のスクリプトでビルドしており、
CI の一環としてビルドできることを確認しています。
現在、この Snap を正式に Ghostty プロジェクトへ移管し、Linux 向けに公式サポート・配布するパッケージ形式の 1 つにするために取り組んでいます。
</Note>

### Solus {/* #solus */}

```sh
eopkg install ghostty
```

### Ubuntu {/* #ubuntu */}

Ghostty は Ubuntu 26.04 以降、公式パッケージリポジトリで利用できます。

> [!NOTE]
> 公式リポジトリに常に最新の Ghostty があるとは限りません。
> Ghostty が最新でない場合は、代わりに[コミュニティの .deb パッケージ](#debian-and-ubuntu)のインストールも検討できますが、
> 非公式パッケージの使用に伴う通常のリスクは変わりません。

```sh
apt install ghostty
```


## Linux（コミュニティのバイナリ） {/* #linux-(community-binaries) */}

このセクションのパッケージは Ghostty のバイナリを提供しますが、該当するディストリビューションの公式パッケージではありません。

<Warning>

コミュニティのバイナリは、Ghostty プロジェクトやディストリビューションのメンテナーが直接提供するビルドに比べて、はるかに高いリスクを伴います。
Ghostty プロジェクトやディストリビューションのメンテナーがパッケージをコンパイルする環境と同じセキュリティ基準を満たしていないかもしれないコンピューターで、事前にコンパイルされているためです。

明確にしておくと、**これらのパッケージをインストールすることで、サードパーティーが悪意を持ってバイナリファイルを改ざんする可能性があるというリスクを暗黙に受け入れることになります**。

セキュリティ上の懸念だけでなく、お使いのコンピューターとバイナリパッケージをビルドしたコンピューターのアーキテクチャの違いや、
ビルド時のコンパイルフラグによっては、気付かないうちに不具合が起こる可能性もあります。

こうしたリスクを許容できるなら、コミュニティのビルドを自由にお使いください。
そうでなければ、[ソースからのコンパイル](/docs/install/build)がはるかに安全な選択肢です。

</Warning>

### Fedora {/* #fedora */}

Ghostty は [Fedora COPR](https://copr.fedorainfracloud.org/coprs/scottames/ghostty/) で利用できます。

```sh
dnf copr enable scottames/ghostty
dnf install ghostty
```

Ghostty は [Terra](https://terra.fyralabs.com/) でも利用できます。

 ```sh
 dnf install --nogpgcheck --repofrompath 'terra,https://repos.fyralabs.com/terra$releasever' terra-release
 dnf install ghostty
 ```

#### Atomic デスクトップ（Silverblue） {/* #atomic-desktops-(silverblue) */}

システムに copr リポジトリを追加します。

```sh
. /etc/os-release
curl -fsSL "https://copr.fedorainfracloud.org/coprs/scottames/ghostty/repo/fedora-${VERSION_ID}/scottames-ghostty-fedora-${VERSION_ID}.repo" | sudo tee /etc/yum.repos.d/_copr:copr.fedorainfracloud.org:scottames:ghostty.repo > /dev/null
```

リポジトリを追加したら、Ghostty をインストールします。

```sh
rpm-ostree refresh-md && \
rpm-ostree install ghostty
```

### Debian と Ubuntu {/* #debian-and-ubuntu */}

> [!NOTE]
> Ghostty は Ubuntu 26.04 以降の公式 Ubuntu パッケージリポジトリに含まれており、
> [公式 Ubuntu パッケージ](#ubuntu)の手順でインストールできます。
> ただし、コミュニティパッケージのほうが公式パッケージより新しい場合もあり、
> 古い Ubuntu では唯一のビルド済みの選択肢でもあります。

Ubuntu と Debian 向けにコミュニティがビルドした Ghostty の .deb パッケージが、GitHub の
[ghostty-ubuntu](https://github.com/mkasberg/ghostty-ubuntu) で利用できます。次のコマンドでインストールできます。

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/mkasberg/ghostty-ubuntu/HEAD/install.sh)"
```

### 汎用 AppImage {/* #universal-appimage */}

Ghostty は、あらゆる Linux ディストリビューション（musl ベースを含む）に対応する汎用 AppImage として利用できます。
GitHub の [ghostty-appimage](https://github.com/pkgforge-dev/ghostty-appimage) から入手できます。

まず、[Releases](https://github.com/pkgforge-dev/ghostty-appimage/releases) ページから適切な `.appimage` ファイルをダウンロードし、
以下の手順に従ってください。

```bash
chmod a+x Ghostty-${VERSION}-${ARCH}.appimage
./Ghostty-${VERSION}-${ARCH}.appimage
```

詳しいインストール手順は、[インストールガイド](https://github.com/pkgforge-dev/ghostty-appimage#%EF%B8%8F-installation)を参照してください。
