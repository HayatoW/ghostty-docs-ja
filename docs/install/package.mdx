<Warning>
**このページは、ほかの人に提供するために Ghostty をビルドしてパッケージ化したい方を対象としています。** Ghostty を使いたいだけの場合は、
[インストール手順](/download)に従ってください。
</Warning>

Ghostty は、エンドユーザーへの配布を下流のパッケージメンテナーに頼っています。
お使いのプラットフォーム向けに Ghostty をパッケージ化することに興味を持っていただき、_心より感謝します_。

Ghostty のソースツリー内に
[パッケージ化ガイド](https://github.com/ghostty-org/ghostty/blob/main/PACKAGING.md)
を用意しています。Ghostty のパッケージ化に関する最新の情報は、このガイドを参照してください。

ご質問やお困りのことがあれば、喜んでお手伝いします。
Ghostty リポジトリで直接 issue を作成してください。
