## 組み込みテーマ {/* #built-in-themes */}

Ghostty には数百種類のテーマが組み込まれており、[`theme` 設定オプション](/docs/config/reference#theme)を使って 1 行の設定で選択できます。たとえば、人気の Catppuccin テーマを使うには、次のようにします。

```ini
theme = Catppuccin Frappe
```

<Tip>
  テーマを変更した後は、忘れずに[設定を再読み込み](/docs/config#reloading-the-configuration)してください。
</Tip>

組み込みテーマは
[iterm2-color-schemes](https://iterm2colorschemes.com) から取得し、
Ghostty リポジトリの main ブランチで毎週更新しています。
新しいテーマを提供したい場合は、iterm2-color-schemes に提供してください。
Ghostty にも自動的に取り込まれます。

### 利用可能なテーマの一覧 {/* #listing-available-themes */}

利用可能なテーマの一覧を見るには、`+list-themes` CLI を使用します。

```sh
ghostty +list-themes
```

組み込みテーマの一覧は、[iterm2-color-schemes](https://iterm2colorschemes.com) でもオンラインで確認できます。
各テーマのプレビューも掲載されています。

## ライトテーマとダークテーマの個別指定 {/* #separate-light-and-dark-themes */}

Ghostty は、ライトテーマとダークテーマを個別に指定できます。

```ini
theme = dark:Catppuccin Frappe,light:Catppuccin Latte
```

ライトテーマとダークテーマを個別に指定すると、Ghostty はシステムの外観に合わせて自動的にテーマを切り替えます。

## カスタムテーマの作成 {/* #authoring-a-custom-theme */}

テーマは Ghostty のほかの設定ファイルと変わりません。通常は色のオプションだけを設定しているにすぎません。
ただし、テーマファイルでは、カーソルのスタイルやフォントなど、あらゆる設定オプションを設定*できます*。

<Warning>
  テーマはあらゆる設定オプションを変更できるため、信頼できない提供元のテーマには注意してください。
  使用する前に必ずテーマファイルを確認し、悪意のある設定が含まれていないことを確かめてください。
</Warning>

テーマファイルと通常の設定ファイルの主な違いは、読み込み方法です。
テーマは*先に*読み込まれ、競合するオプションがユーザー設定にあれば、そちらがテーマを上書きします
（ユーザー設定の*後に*読み込まれる
[`config-file`](/docs/config/reference#config-file) とは異なります）。

カスタムテーマを作成するには、新しいファイルを作成し、次のオプションを設定します。

  - [`background`](/docs/config/reference#background)
  - [`foreground`](/docs/config/reference#foreground)
  - [`cursor-color`](/docs/config/reference#cursor-color)
  - [`selection-foreground`](/docs/config/reference#selection-foreground)
  - [`selection-background`](/docs/config/reference#selection-background)
  - [`palette`](/docs/config/reference#palette)

### ファイルの場所 {/* #file-location */}

テーマファイルはファイルシステム上のどこに置いてもかまいません。
[`theme`](/docs/config/reference#theme) 設定オプションでは絶対パスを指定できます。
ただし、名前でテーマを参照する場合は、特定のディレクトリに置く必要があります。

名前によるテーマの検索では、次の 2 つのディレクトリを調べます。

  1. `$XDG_CONFIG_HOME/ghostty/themes`
  2. `$PREFIX/share/ghostty/themes`

