## 概要 {/* #overview */}

macOS 版 Ghostty はネイティブの AppleScript 辞書を公開しており、スクリプトからターミナルのウィンドウ、タブ、分割ペインの情報を取得し、制御できます。
これにより、`osascript`、ランチャーのワークフロー、エディタープラグイン、独自の自動化スクリプトなどと Ghostty を簡単に連携できます。

AppleScript 対応は Ghostty 1.3.0 で導入されました。

## スクリプティング辞書 {/* #scripting-dictionary */}

AppleScript API の正確な定義は、Ghostty のスクリプティング定義ファイル
<a href="https://github.com/ghostty-org/ghostty/blob/main/macos/Ghostty.sdef">Ghostty.sdef</a> にあります。
スクリプトエディタで読み込み、macOS の GUI を使って API を閲覧するのが最も便利です。

インストール済みのアプリバンドルから辞書を確認するには、次を実行します。

```sh
sdef /Applications/Ghostty.app | less
```

スクリプトが動作することを確認するには、次を実行します。

```sh
osascript -e 'tell application "Ghostty" to get version'
```

## オブジェクトモデル {/* #object-model */}

Ghostty の AppleScript モデルは階層構造です。

```text
application -> windows -> tabs -> terminals
```

| オブジェクト | 主なプロパティ | 主な要素 |
| ------ | -------------- | ------------ |
| `application` | `name`, `frontmost`, `front window`, `version` | `windows`, `terminals` |
| `window` | `id`, `name`, `selected tab` | `tabs`, `terminals` |
| `tab` | `id`, `name`, `index`, `selected`, `focused terminal` | `terminals` |
| `terminal` | `id`, `name`, `working directory` | なし |

`front window` は最前面の Ghostty ウィンドウを返します。`focused terminal` はタブ内のアクティブなターミナルを返します。
現在フォーカスされているターミナルを操作するスクリプトに便利です。

### オブジェクトの取得例 {/* #object-query-examples */}

```AppleScript
tell application "Ghostty"
    set win to front window
    set tab1 to selected tab of win
    set term1 to focused terminal of tab1
    set allTermsInWin to terminals of win

    set cwdMatches to every terminal whose working directory contains "ghostty"
end tell
```

この 2 つのプロパティにより、アクティブなコンテキストを操作するスクリプトを簡潔に書けます。

```AppleScript
tell application "Ghostty"
    set term to focused terminal of selected tab of front window
    input text "pwd\n" to term
end tell
```

```AppleScript
tell application "Ghostty"
    set currentTerm to focused terminal of selected tab of front window
    set newTerm to split currentTerm direction right
    input text "echo split-ready\n" to newTerm
end tell
```

## コマンド {/* #commands */}

### 作成とレイアウト {/* #creation-and-layout */}

| コマンド | 用途 | 構文例 |
| ------- | ------- | -------------- |
| `new surface configuration` | 再利用可能なサーフェス設定レコードを作成します。 | `set cfg to new surface configuration` |
| `new window` | 新しいウィンドウを作成します。 | `set win to new window with configuration cfg` |
| `new tab` | 新しいタブを作成します。対象ウィンドウは任意で指定できます。 | `set t to new tab in win with configuration cfg` |
| `split` | ターミナルを分割し、新しいターミナルを返します。 | `set t2 to split t1 direction right with configuration cfg` |

`split direction` の値は `right`、`left`、`down`、`up` です。

### フォーカス、選択、ライフサイクル {/* #focus-selection-and-lifecycle */}

| コマンド | 用途 | 構文例 |
| ------- | ------- | -------------- |
| `focus` | ターミナルにフォーカスし、そのウィンドウを最前面に移動します。 | `focus t1` |
| `activate window` | ウィンドウを最前面に移動します。 | `activate window (window 1)` |
| `select tab` | タブを選択します。 | `select tab (tab 2 of window 1)` |
| `close` | ターミナルを閉じます。 | `close (terminal 2 of selected tab of window 1)` |
| `close tab` | タブを閉じます。 | `close tab (tab 2 of window 1)` |
| `close window` | ウィンドウを閉じます。 | `close window (window 1)` |

### 入力とアクション {/* #input-and-actions */}

| コマンド | 用途 | 構文例 |
| ------- | ------- | -------------- |
| `input text` | 貼り付け形式のテキスト入力をターミナルに送信します。 | `input text "echo hello" to t1` |
| `send key` | キーの押下・解放イベントを送信します。修飾キーも任意で指定できます。 | `send key "enter" to t1` |
| `send mouse button` | マウスボタンのイベントを送信します。 | `send mouse button left button to t1` |
| `send mouse position` | ポインター位置の更新を送信します。 | `send mouse position x 240 y 120 to t1` |
| `send mouse scroll` | 精密スクロールや慣性のオプション付きでスクロールイベントを送信します。 | `send mouse scroll x 0 y -8 precision true to t1` |
| `perform action` | ターミナルで Ghostty のアクション文字列を実行します。 | `perform action "toggle_fullscreen" on t1` |

`send key` と `send mouse button` の `action` は、`press` または `release` です。
`modifiers` は、次のいずれかを含むカンマ区切りの文字列です。
`shift`, `control`, `option`, `command`.

`perform action` のアクション文字列は、キーバインド設定で使うアクション名と同じです。
[キーバインドアクションリファレンス](/docs/config/keybind/reference)を参照してください。

## サーフェス設定レコード {/* #surface-configuration-records */}

`new surface configuration` は、`new window`、`new tab`、`split` に渡せる再利用可能な値のレコードを作成します。

サポートするフィールドは次のとおりです。

- `font size`
- `initial working directory`
- `command`
- `initial input`
- `wait after command`
- `environment variables`（`KEY=VALUE` 文字列のリスト）

例:

```AppleScript
tell application "Ghostty"
    set cfg to new surface configuration
    set initial working directory of cfg to POSIX path of (path to home folder) & "src/ghostty"
    set font size of cfg to 13
    set environment variables of cfg to {"EDITOR=nvim", "FZF_DEFAULT_OPTS=--height 40%"}

    set win to new window with configuration cfg
end tell
```

## セキュリティ {/* #security */}

macOS では、AppleScript 対応はデフォルトで有効です。
macOS はオートメーション権限（TCC）でアプリ間の自動化を保護するため、
ほかのアプリが Ghostty を制御する前に、システムが確認を求めます。

AppleScript 対応を完全に無効にするには、次のように設定します。

```ini
macos-applescript = false
```

## 使用例 {/* #examples */}

### Tmux 風のレイアウトを作成する {/* #build-a-tmux-style-layout */}

```AppleScript
set projectDir to POSIX path of (path to home folder) & "src/ghostty"

tell application "Ghostty"
    activate

    set cfg to new surface configuration
    set initial working directory of cfg to projectDir

    set win to new window with configuration cfg
    set paneEditor to terminal 1 of selected tab of win
    set paneBuild to split paneEditor direction right with configuration cfg
    set paneGit to split paneEditor direction down with configuration cfg
    set paneLogs to split paneBuild direction down with configuration cfg

    input text "nvim ." to paneEditor
    send key "enter" to paneEditor

    input text "zig build -Demit-macos-app=false" to paneBuild
    send key "enter" to paneBuild

    input text "git status -sb" to paneGit
    send key "enter" to paneGit

    input text "tail -f /tmp/dev.log" to paneLogs
    send key "enter" to paneLogs

    focus paneEditor
end tell
```

### すべてのターミナルにコマンドを一斉送信する {/* #broadcast-a-command-to-every-terminal */}

```AppleScript
set cmd to "date"

tell application "Ghostty"
    set allTerms to terminals

    repeat with t in allTerms
        input text cmd to t
        send key "enter" to t
    end repeat

    display dialog ("Broadcasted to " & (count of allTerms) & " terminal(s).")
end tell
```

### タブのタイトルを設定する {/* #set-tab-titles */}

`perform action` と `set_tab_title` を使って、スクリプトからタブにラベルを付けられます。

新しいタブを作成してタイトルを設定する例です。

```AppleScript
tell application "Ghostty"
    set win to front window
    set cfg to new surface configuration

    set t1 to new tab in win with configuration cfg
    perform action "set_tab_title:Editor" on focused terminal of t1
    input text "nvim .\n" to focused terminal of t1

end tell
```

### 作業ディレクトリを指定してターミナルに移動する {/* #jump-to-a-terminal-by-working-directory */}

```AppleScript
set needle to "ghostty"

tell application "Ghostty"
    set matches to every terminal whose working directory contains needle

    if (count of matches) = 0 then
        set matches to every terminal whose name contains needle
    end if

    if (count of matches) > 0 then
        set t to item 1 of matches
        focus t
        input text "echo '[focused by AppleScript]'" to t
        send key "enter" to t
    end if
end tell
```
