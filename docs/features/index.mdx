Ghostty は、非常に多機能なターミナルです。

ターミナルの機能は、エンドユーザー向けの機能と、ターミナルアプリケーション開発者向けの機能の 2 つに分けられます。

エンドユーザー向けの機能には、複数ウィンドウ、タブ、分割、合字、自動更新などがあります。
これらは、実行中のターミナルアプリケーション（シェルやテキストエディターなど）に変更を加えることなく、ターミナルをより快適に使えるようにする機能です。

ターミナルアプリケーション開発者向けの機能には、Kitty グラフィックスプロトコル、Kitty キーボードプロトコル、
同期レンダリング、ライトモード / ダークモードの通知などがあります。
これらにより、ターミナルアプリケーションはほかのターミナルエミュレーターよりも多くのことができるようになります。
エンドユーザーが直接使う機能ではありませんが、日常的に使うターミナルアプリケーションの可能性が広がるため、エンドユーザーにも恩恵があります。

## 主な機能 {/* #feature-highlight */}

Ghostty がサポートする主な機能や、特に興味深い機能を紹介します。

- **クロスプラットフォーム**: Ghostty は macOS と Linux で動作します。
  各プラットフォームのネイティブ UI コンポーネントを使い、その環境になじむ操作感を提供します。
  Windows への対応は今後予定しています。

- **ウィンドウ、タブ、分割**: Ghostty は複数のウィンドウをサポートし、それぞれにタブや分割を作成できます。
  これらはすべてネイティブ UI コンポーネントで描画されます。

- **GPU アクセラレーションによる描画**: Ghostty は、macOS では Metal、Linux では OpenGL を使ってターミナル画面を描画します。

- **テーマ**: Ghostty には数百種類のテーマが付属し、1 行の設定で選択できます。
  システムのダークモード / ライトモードに応じて自動的に切り替えることもできます。
  独自のテーマを作成することも可能です。

- **合字**: 合字を持つフォントを使用でき、Ghostty はそれらを正しく描画します。
  特定のフォント機能の有効・無効も指定できます。

- **書記素クラスタリング**: 国旗や肌の色など、複数のコードポイントからなる絵文字を 1 文字として正しく描画します。
  アラビア文字やヘブライ文字など、一部の右から左に書く文字体系の個々の書記素クラスタも正しく描画します。
  ただし、対応するテキストの方向は左から右のみです。

- **Kitty グラフィックスプロトコル**: Ghostty は Kitty グラフィックスプロトコルをサポートし、
  ターミナルアプリケーションがターミナル内に直接画像を描画できるようにします。

### プラットフォームのネイティブ機能 {/* #platform-native-features */}

Ghostty の主要な[設計目標](/docs/about)の 1 つは、各プラットフォーム専用に作られたネイティブアプリケーションのような見た目、操作感、動作を実現することです。
Ghostty が備えるプラットフォームのネイティブ機能をいくつか紹介します。

### macOS {/* #macos */}

- **クイックターミナル**: メニューバーの下にアニメーションで現れる軽量なターミナルで、作業を中断せずにすぐアクセスできます。
- **AppleScript による自動化**: ウィンドウ、タブ、ターミナル、レイアウト、入力イベントをスクリプトで操作するための AppleScript 辞書を内蔵しています。
  [AppleScript ドキュメント](/docs/features/applescript)を参照してください。
- **ネイティブのタブや分割など**: ほかのターミナルエミュレーターのように独自に描画したテキストではなく、タブや分割などの UI 要素に macOS のネイティブコンポーネントを使います。
- **プロキシアイコン**: タイトルバーのプロキシアイコンをドラッグしてターミナルセッションのファイルを移動したりアクセスしたり、ファイルパスに直接移動したりできます。
- **クイックルック**: テキストを 3 本指でタップするか強く押すと、macOS のクイックルックで辞書検索やウェブ検索などができます。
- **セキュアキーボード入力**: パスワードプロンプトを自動検出するか、手動でセキュアキーボード入力を有効にして、パスワードをほかのプロセスから保護します。
  有効なときはターミナルの右上にアニメーション付きの鍵アイコンが表示されます。

## ターミナル（VT）機能 {/* #terminal-(vt)-features */}

ターミナルアプリケーション開発者にとって、Ghostty は最も現代的で包括的なターミナルエミュレーターの 1 つだと考えています[^1]。
Ghostty の目標は、従来のアプリケーションとの最高の互換性を保ちながら、
新しいアプリケーションには最先端の機能を提供することです。

具体的には、Ghostty は幅広い制御シーケンス、ターミナル機能、ターミナルプロトコルをサポートしています。
これらの機能の動作を決める際は、次の原則に従います。

  1. Xterm との互換性: xterm はターミナルエミュレーションの事実上の標準です。
     xterm が何かを行うなら、私たちも同じようにするべきです[^2]。

  2. プロトコルの起源との互換性: プロトコルを定義したターミナルが特定の動作をするなら、
     仕様に書かれていなくても、その動作に従うべきです[^3]。

  3. 事実上の標準との互換性: ある動作が標準として広く受け入れられているなら、その動作に従うべきです。
     「広く受け入れられている」かどうかは、一般に世論や使用状況に基づく主観的な判断です。

Ghostty がサポートするターミナル開発者向け機能の一覧は、
[リファレンス](/docs/vt/reference)を参照してください
（ただし、執筆時点ではまだ作成途中です）。

[^1]: そうでないと感じたら、ぜひ教えてください！
[ディスカッションを作成](https://github.com/ghostty-org/ghostty/discussions)してください。
[^2]: xterm の動作に疑問がある場合や、広く受け入れられていない場合は、設定フラグで切り替えるようにすることがあります。
[^3]: 仕様とプロトコルを定義したターミナルの動作が異なる場合は、ディスカッションを作成して正しい動作を判断します。
